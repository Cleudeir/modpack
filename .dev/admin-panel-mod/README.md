# Admin Panel Mod - Minecraft 1.20.1

Real clickable admin GUI menu for Minecraft Forge 1.20.1.

## How to use
- Press **Right Control** to open the menu
- Click buttons to execute admin commands
- Press **ESC** to close

## Tabs
- **Player** - Heal, Feed, Fly, God Mode, Speed, Effects
- **Items** - Give diamonds, netherite, elytra, etc.
- **World** - Time, Weather, Difficulty, Teleport
- **Mobs** - Kill all, Player list
- **Mods** - Mod info and help

## Build
```bash
gradle build
```
Output: `build/libs/admin-gui-1.0.0.jar`

## Install
Copy the jar to your `mods/` folder.

## Requirements
- Minecraft 1.20.1
- Forge 47.3.0+
