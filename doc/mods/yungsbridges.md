# YUNG's Bridges

**Version:** 4.0.3
**Category:** World Generation

## Description

Adds bridge structures throughout the Overworld, connecting landmasses and crossing rivers and ravines. These structures add variety to exploration and can be useful waypoints.

## Key Features

- Bridges spawn across rivers and ravines
- Multiple bridge styles
- Some bridges have chests with loot
- Adds atmosphere to world exploration
- Connects terrain features naturally

## Configuration

Config file: `config/yungsbridges.toml`

Key settings:
- Bridge spawn frequency
- Bridge size and style
- Loot settings

## Tips

- Bridges make great navigation landmarks
- Some contain loot chests
- Look for them crossing rivers and ravines
- Adds nice visual variety to the world
