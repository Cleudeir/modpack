# YUNG's API

**Version:** 4.0.5
**Category:** Library / API

## Description

YUNG's API is a required library mod for all of YUNG's mods. It provides shared utilities and hooks that other YUNG mods depend on. This mod must be installed for any YUNG's Better... or YUNG's Bridges/Extras mods to function.

## Key Features

- Core library for all YUNG's mods
- Shared configuration system
- Structure generation utilities
- Biome modification hooks
- Mixin utilities

## Configuration

No standalone configuration - settings are managed by individual YUNG mods.

## Tips

- Always install this before any other YUNG's mods
- Keep it updated to the latest version for compatibility
- Check version compatibility when updating other YUNG mods
- Required dependency - the game will crash without it
