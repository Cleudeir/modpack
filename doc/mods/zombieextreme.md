# Zombie Extreme

**Version:** 0.2.4
**Category:** Adventure & Dungeons

## Description
Zombie Extreme adds hardcore zombie survival mechanics with enhanced AI, new zombie variants, and intense combat scenarios. Features improved zombie behavior, special abilities, and a more challenging survival experience.

## Key Features
- Enhanced zombie AI with tactical behavior
- Special zombie variants with unique abilities
- Improved pathfinding and coordination
- Difficulty scaling based on player progress
- Integration with zombie awareness systems
- Hardcore survival mechanics

## Configuration
**Config file:** Resource pack configuration in `config/paxi/resourcepacks/zombieextreme/`

Key settings:
- Configuration managed through resource packs
- Mod behavior can be adjusted via datapacks
- Works alongside Zombie Awareness mod for enhanced behavior
- Compatible with other zombie modification mods

## Tips
- Combine with Zombie Awareness for maximum difficulty
- Prepare fortified bases before nightfall
- Use ranged weapons to deal with groups from a distance
- Sound management is crucial - zombies respond to noise
- Iron golems and wall defenses become essential at higher difficulties
