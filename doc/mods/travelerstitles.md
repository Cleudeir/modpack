# Traveler's Titles

**Version:** 4.0.2
**Category:** Exploration & Navigation

## Description
Traveler's Titles displays cinematic titles when players enter new biomes, dimensions, or discover waystones. It adds immersion to exploration by announcing location discoveries.

## Key Features
- Biome discovery titles with customizable text
- Dimension entry announcements
- Waystone discovery titles (requires Waystones mod)
- Configurable text color, size, and position
- Fade-in/out animations
- Cooldown to prevent spam
- Biome/dimension blacklisting

## Configuration
Config file: `config/travelerstitles-forge-1_20.toml`

Key settings:
- `Enable Biome Titles` - Show biome titles (default: true)
- `Text Display Time` - Duration in ticks (default: 50)
- `Text Cooldown Time` - Minimum time between titles (default: 60)
- `Default Text Color` - Title color (default: "ffffff")
- `Text Size` - Title scale (default: 2.1)
- `Blacklisted Biomes` - Biomes to ignore
- `Only Show Biome Titles When Exposed To Skylight` - Underground titles (default: true)

## Tips
- Titles add immersion to exploration
- Blacklist frequently visited biomes to reduce spam
- Waystone titles require Waystones mod to be installed
- Custom sounds can be added via resource packs
- Text position can be adjusted with X/Y offsets
