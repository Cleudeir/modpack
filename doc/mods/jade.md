# Jade

**Version:** 11.x.x
**Category:** Quality of Life

## Description
Jade (formerly WAILA/HWYLA) provides an information overlay when looking at blocks and entities. It shows what you're looking at, what mod it's from, and useful metadata like block states and harvest levels.

## Key Features
- Shows block/entity name and mod source
- Displays harvest level and tool requirements
- Shows block states and properties
- Configurable overlay position and appearance
- Supports modded blocks and entities
- Show/hide specific information

## Configuration
Config file: `config/jade.json`

Key settings:
- `overlayX/Y` - Position of the overlay
- `showHarvestLevel` - Display harvest requirements
- `showModName` - Show which mod the block is from
- `backgroundColor` - Overlay background color

## Tips
- Press the keybind (default: Numpad 1) to toggle the overlay
- Right-click the overlay for more detailed information
- Works great with mining mods to see ore harvest levels
- Can be configured to show fluid amounts in tanks
