# Game Stages

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A mod that allows modpack developers to create progression-based content unlocking. Players must complete specific tasks or meet conditions to unlock access to new items, blocks, recipes, and dimensions.

## Key Features
- Custom game stages that can be unlocked via commands or events
- Item and block restrictions based on stages
- Recipe unlocking tied to progression
- Integration with many popular mods
- Customizable stage requirements and rewards

## Configuration
Config files are located in `config/gamestages/`. Key settings include:
- Stage definitions and unlock conditions
- Item/block restriction lists
- Recipe unlock configurations
- Default stage assignments

## Tips
- Use `/gamestage add @s [stage]` to manually add stages
- Stages can be granted via achievements, quests, or commands
- Check mod integration guides for compatibility
- Use in conjunction with Item Stages for item restrictions
