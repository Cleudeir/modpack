# Cloth Config

**Version:** 11.1.118
**Category:** Utility & Library

## Description
Cloth Config is a configuration API that provides a rich set of widgets for building config screens. It enables mods to have user-friendly configuration interfaces.

## Key Features
- Config screen builder
- Multiple widget types (sliders, toggles, dropdowns)
- Category organization
- Search functionality
- Preset support
- Undo/redo functionality

## Configuration
- Accessed through mod options in the Mods menu
- Config files stored in `config/` directory

## Tips
- Many mods use Cloth Config for their settings screens
- Press the config button in the Mods menu to access
- Some configs require game restart to take effect
