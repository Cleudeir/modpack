# Ecologics

**Version:** 2.2.0
**Category:** Building & Decoration

## Description
Ecologics is a nature-themed decoration mod that adds blocks and items inspired by nature and ecology. It provides decorative elements for creating natural, organic builds and garden spaces.

## Key Features
- Plant varieties (flowers, bushes, trees)
- Nature-themed decorations
- Garden furniture and features
- Natural building materials
- Environmental blocks (moss, vines, etc.)
- Outdoor decorations

## Configuration
Config file: `config/ecologics.toml`
- Toggle specific block categories
- Adjust generation settings

## Tips
- Perfect for garden and park builds
- Combine with Handcrafted for natural-themed furniture
- Great for creating organic, nature-inspired builds
- Works well with Supplementaries for additional decorative options
