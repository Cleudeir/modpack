# Just Enough Items (JEI)

**Version:** 15.x.x
**Category:** Quality of Life

## Description
JEI is an essential recipe viewer and item lookup mod for Minecraft. It allows players to quickly search for items, view crafting recipes, and see usage information for any item in the game.

## Key Features
- Browse all items and blocks in the game
- View crafting recipes for any item (press R on an item)
- See all uses for any item (press U on an item)
- Search items by name in the inventory
- Bookmark items for quick access
- Recipe transfer buttons in crafting tables

## Configuration
Config file: `config/jei/client.ini`

Key settings:
- `CreativeTabMode` - How JEI appears in creative tabs
- `ShowRecipesButton` - Toggle recipe button in inventory
- `ShowSearchBar` - Toggle search bar visibility

## Tips
- Press `R` while hovering over an item to see its recipe
- Press `U` to see all uses for an item
- Use the search bar at the bottom of your inventory
- Bookmarks are saved across sessions
- JEI works with most modded items automatically
