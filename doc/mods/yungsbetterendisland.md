# YUNG's Better End Island

**Version:** 2.0.6
**Category:** World Generation

## Description

Overhauls the End Island (main island) with a much larger, more detailed structure. The End City area becomes a massive explorable space with better loot and more interesting terrain.

## Key Features

- Larger and more detailed main End Island
- Improved End City generation
- Better loot distribution
- More interesting terrain and features
- Enhanced End gateway generation

## Configuration

Config file: `config/yungsbetterendisland.toml`

Key settings:
- Island size and complexity
- Loot quality
- Feature spawn rates

## Tips

- The main island is much larger - bring an elytra for exploration
- Better loot makes the End more rewarding
- End Cities are more detailed and varied
- Works great with other End-enhancing mods
