# Entropy

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A mod that introduces magic and decay mechanics, adding entropy as a magical force. It features spells, rituals, and environmental effects based on magical entropy.

## Key Features
- Entropy-based magic system
- Decay mechanics for blocks and items
- Spells and rituals using entropy
- Environmental magical effects
- Integration with other magic mods

## Configuration
Config files are located in `config/entropy/`. Key settings include:
- Entropy generation and decay rates
- Spell power and effects
- Ritual requirements and outcomes
- Environmental effect parameters

## Tips
- Manage entropy levels to prevent unwanted decay
- Use entropy spells strategically for maximum effect
- Some blocks are resistant to entropy decay
- Combine with other magic systems for powerful synergies
