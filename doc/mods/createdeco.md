# Create Deco

**Version:** 2.0.2 (1.20.1)
**Category:** Technology & Automation / Decoration

## Description
Create Deco adds a large collection of decorative blocks themed around Create's mechanical aesthetic. It provides industrial-style doors, trapdoors, walls, stairs, slabs, and other building blocks for factory and workshop builds.

## Key Features
- **Industrial Doors** - Large rolling doors, garage doors, and hinged doors
- **Trapdoors** - Multiple sizes and styles (large, small, and functional)
- **Walls, Stairs & Slabs** - Decorative variants for all Create materials
- **Andesite, Brass & Copper Variants** - Blocks for each metal tier
- **Framed Glass** - Decorative glass with metal frames
- **Factory Decorations** - Industrial aesthetic blocks for immersive builds

## Configuration
No dedicated config file was found. This mod is purely decorative and adds blocks without requiring configuration.

## Tips
- Great for creating factory/workshop interiors that match Create's aesthetic
- Pairs well with Create's block palette for seamless integration
- Doors and trapdoors function like vanilla variants (can be opened/closed)
- Use alongside design_decor and other decoration mods for maximum variety
