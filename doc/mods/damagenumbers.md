# Damage Numbers

**Version:** 1.20.1-1.2.1
**Category:** Combat & Weapons

## Description
Damage Numbers displays floating damage values when you hit entities. Shows exact damage dealt with color coding for different damage types.

## Key Features
- Floating damage numbers on hit
- Color coding for damage types (physical, magic, fire)
- Critical hit indicators
- Heal number display
- Customizable font and size

## Configuration
Config file: `config/damagenumbers.toml`
- `numberColor` - Default damage color
- `critColor` - Critical hit color
- `fontSize` - Damage number size
- `floatSpeed` - Number float animation speed

## Tips
- Useful for balancing weapon damage
- Helps understand damage reduction from armor
- Disable if distracting in combat
- Works with most damage sources
