# Pehkui

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A mod that adds size-changing abilities, allowing players and entities to grow larger or smaller. It provides various potions, enchantments, and commands for controlling size.

## Key Features
- Size-changing potions and effects
- Scale modifiers for different body parts
- Commands for adjusting size
- Integration with other mods for scaled interactions
- Configurable size ranges and effects

## Configuration
Config files are located in `config/pehkui/`. Key settings include:
- Minimum and maximum size limits
- Potion effect durations and potency
- Scaling behavior options
- Integration settings with other mods

## Tips
- Start with small size changes before going extreme
- Some mobs and blocks may not work well at extreme sizes
- Use potions for temporary changes, commands for permanent
- Check compatibility with other mods at extreme scales
