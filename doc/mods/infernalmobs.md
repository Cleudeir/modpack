# Infernal Mobs

**Version:** 1.20.1-4.1.0
**Category:** Mobs & Entities

## Description
Infernal Mobs makes hostile mobs occasionally spawn with elite modifiers that grant them special abilities. These "infernal" mobs are tougher but drop better loot.

## Key Features
- Random elite modifiers on hostile mobs
- 20+ unique modifiers (speed, regeneration, etc.)
- Visual indicators for infernal mobs
- Increased XP and loot drops
- Configurable modifier chances
- Works with most entity types

## Configuration
Config file: `config/infernalmobs.cfg`

Key settings:
- Modifier chance per mob
- Individual modifier enable/disable
- Health and damage bonuses
- Loot multiplier settings

## Tips
- Infernal mobs have particle effects indicating their modifiers
- Some modifier combinations are extremely dangerous
- Fire resistance helps against fire-based modifiers
- Higher difficulty increases infernal spawn rates
