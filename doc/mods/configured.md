# Configured

**Version:** 2.2.3
**Category:** Utility & Library

## Description
Configured is a config screen factory that automatically generates configuration GUIs for mods using Forge's config system. It makes config editing accessible in-game.

## Key Features
- Automatic config screen generation
- Forge config integration
- In-game config editing
- Category organization
- Widget customization

## Configuration
- Accessed through the Mods menu -> Config button
- Works with Forge config files in `config/`

## Tips
- Click the config icon next to mod names in the Mods list
- Some changes require game restart
- Works alongside Cloth Config for enhanced screens
