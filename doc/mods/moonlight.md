# Moonlight Lib

**Version:** 2.12.17
**Category:** Utility & Library

## Description
Moonlight Lib is a shared library used by multiple mods. It provides common utilities for block entities, item rendering, and configuration management.

## Key Features
- Block entity utilities
- Item property helpers
- Configuration API
- Network abstractions
- Rendering utilities
- Tag helpers

## Configuration
No direct configuration - this is a dependency library.

## Tips
- Required by mods like Handcrafted and Storage Racks
- Safe to keep installed as a general utility
- Update when updating dependent mods
