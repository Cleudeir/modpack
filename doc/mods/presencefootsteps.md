# Presence Footsteps

**Version:** 1.8.x
**Category:** Quality of Life

## Description
Presence Footsteps adds realistic and varied footstep sounds based on the block you're walking on. It makes movement more immersive with different sounds for different surfaces.

## Key Features
- Realistic footstep sounds
- Surface-based sound variations
- Different sounds for walking, running, sneaking
- Supports modded blocks
- Volume and pitch customization

## Configuration
Config file: `config/presencefootsteps.toml`

Key settings:
- `volume` - Overall footstep volume
- `pitch` - Pitch variation range
- `echo` - Enable echo effects
- `hardSurfaceSounds` - Sounds for hard surfaces

## Tips
- Great for immersion and atmosphere
- Works with most modded blocks
- Adjust volume if footsteps are too loud
- Pairs well with Sound Physics
