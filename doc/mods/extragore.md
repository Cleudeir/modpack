# Extra Gore

**Version:** 1.20.1-1.0.5
**Category:** Combat & Weapons

## Description
Extra Gore adds blood and gore effects to combat. Features particle effects, sound effects, and visual indicators for damage dealt.

## Key Features
- Blood particles on hit
- Gore effects on critical hits
- Sound effects for different damage types
- Configurable intensity levels
- Client-side only for multiplayer compatibility

## Configuration
Config file: `config/extragore.toml`
- `particleIntensity` - Blood particle amount
- `soundEnabled` - Toggle gore sounds
- `criticalEffects` - Critical hit effects
- `entityTypes` - Which entities show effects

## Tips
- Disable for stream-friendly mode
- Reduce particles on lower-end systems
- Combine with Damage Numbers for feedback
- Some effects only show on client side
