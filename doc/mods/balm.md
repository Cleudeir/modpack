# Balm

**Version:** 7.2.2
**Category:** Utility & Library

## Description
Balm is an abstraction layer for mod configurations and other common modding tasks. It simplifies config management across different mod loaders and provides utility functions.

## Key Features
- Simplified configuration API
- Cross-platform config management
- Command registration helpers
- Network packet abstractions
- Event handling utilities

## Configuration
Balm itself has no user-facing configuration. It manages configs for other mods that use its API.

## Tips
- Required by many mods for config management
- Configs created through Balm appear in standard Forge config locations
- If configs aren't appearing, check Balm version compatibility
