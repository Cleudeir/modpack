# FiltPick (Flight Filter)

**Version:** 1.x.x
**Category:** Quality of Life

## Description
FiltPick provides flight filtering for items, allowing you to filter what items are picked up while flying. This is useful for automated farms and filtering systems where you want to control item pickup.

## Key Features
- Item pickup filtering
- Flight mode integration
- Configurable filter lists
- Whitelist/blacklist support
- Works with automation systems

## Configuration
Config file: `config/filtpick.toml`

Key settings:
- `enableFilter` - Toggle filtering
- `filterMode` - Whitelist or blacklist mode
- `filterItems` - List of items to filter
- `flightIntegration` - Enable flight detection

## Tips
- Great for mob farms and auto-collectors
- Use with hoppers for item sorting
- Configure before building farms
- Check compatibility with other mods
