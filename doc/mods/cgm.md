# CGM (Custom Gun Mod)

**Version:** 1.20.1-1.3.4
**Category:** Combat & Weapons

## Description
CGM adds a comprehensive gun system with extensive customization options. Features modular weapon building, attachments, and various ammunition types.

## Key Features
- Modular gun crafting system
- Extensive attachment options (scopes, grips, stocks)
- Multiple ammo types (FMJ, hollow point, tracer)
- Weapon modification bench
- Realistic gun mechanics

## Configuration
Config file: `config/cgm.toml`
- `weaponStats` - Base weapon statistics
- `attachmentEffects` - Attachment modifiers
- `ammoProperties` - Ammo type behaviors
- `recoilPatterns` - Weapon recoil settings

## Tips
- Build guns at the weapon modification bench
- Test different attachments for playstyle
- Tracer ammo helps with long-range shooting
- Combine with Scorched Guns for more variety
