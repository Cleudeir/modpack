# Architectury

**Version:** 9.2.14
**Category:** Utility & Library

## Description
Architectury is a cross-platform modding API that allows mods to be developed for both Forge and Fabric from a single codebase. It provides abstractions for common modding tasks.

## Key Features
- Cross-platform mod development
- Unified event system
- Registry abstractions
- Network packet abstractions
- Screen/GUI abstractions
- Platform-specific code injection

## Configuration
No direct configuration required - this is a library used by other mods.

## Tips
- Required by many multi-platform mods
- If you see Architectury errors, check both Forge and mod versions
- Does not add any gameplay content itself
