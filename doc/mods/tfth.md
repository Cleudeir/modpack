# TFTH (The Flesh That Hates)

**Version:** 1.1b
**Category:** Adventure & Dungeons

## Description
The Flesh That Hates (TFTH) is a horror-themed mod that introduces flesh corruption mechanics, biome infection, and terrifying flesh creatures. Features a point-based system that escalates threat levels as the infection spreads.

## Key Features
- Flesh biome infection and spreading mechanics
- Multiple phases of progression (Embryo, Biogenesis, Enlightenment, Synthesis, Epikulmination)
- Incubator spawning system with configurable timers
- Flesh mobs with unique abilities and behaviors
- Point-based threat escalation system
- Flesh blocks that infect surrounding terrain
- Horror-themed atmosphere with red fog

## Configuration
**Config files:**
- `config/TFTH.toml` - Main configuration
- `config/TFTH-Data.toml` - Loot tables

Key settings:
- `enableIncubatorSpawn` - Enable Incubator spawning - Default: true
- `incubatorSleepTime` - Ticks before Incubator emerges (36000 = 30 min) - Default: 36000
- `ticksBeforeNextSpawn` - Cooldown between Incubators (18000 = 15 min) - Default: 18000
- `distancebetweenincubators` - Minimum distance between Incubators - Default: 2000
- `enableFleshFog` - Enable red horror fog - Default: true
- `enableFleshBlockSpread` - Enable flesh biome spreading - Default: true
- `spreadDuration` - Duration of spread process - Default: 800
- `Range Spread` - Maximum spread range - Default: 1500
- `Global Damage Modifier` - Multiplier for all flesh mob damage - Default: 1.0
- `Global Health Modifier` - Multiplier for all flesh mob health - Default: 1.0

## Tips
- Fire is extremely effective against flesh mobs (2x-7x damage multiplier depending on phase)
- Destroy Flesh Boils to reduce threat points
- Flesh spreads to nearby blocks - contain it early
- Incubators spawn at random intervals - be vigilant
- Higher phases unlock stronger mobs but deal more damage
- Keep your respawn point far from Incubators (80+ blocks)
- The mod integrates with zombie awareness for enhanced flesh behavior
