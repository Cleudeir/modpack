# Effortless Building

**Version:** 3.8 (1.20.1)
**Category:** Technology & Automation / Building Tools

## Description
Effortless Building adds powerful building tools including extended reach, mirrored placement, and bulk block placement. It streamlines large-scale construction by allowing players to place and break blocks at greater distances and in geometric patterns.

## Key Features
- **Extended Reach** - Place/break blocks up to 200 blocks away in Creative
- **Mirrored Placement** - Build symmetrical structures automatically
- **Wall/Floor/Ceiling Modes** - Place blocks in flat planes with one click
- **Bulk Placement** - Place up to 10,000 blocks at once in Creative
- **Upgrade System** - Power Level upgrades increase reach and capacity in Survival
- **Build Modes** - Toggle between normal, mirror, wall, floor, and other modes

## Configuration
**Config files:** `config/effortlessbuilding-common.toml`, `config/effortlessbuilding-client.toml`

Key settings:
- `reachCreative` = `200` blocks max reach in Creative
- `reachLevel0` = `0` (no reach without upgrades in Survival)
- `reachLevel1` = `8`, `reachLevel2` = `16`, `reachLevel3` = `32`
- `maxBlocksPlacedAtOnceCreative` = `10,000`
- `maxBlocksPlacedAtOnceLevel0` = `128` (base survival)
- `maxBlocksPerAxisLevel3` = `20` (max axis size fully upgraded)
- `maxMirrorRadiusLevel3` = `64` blocks

## Tips
- Consume Power Level upgrades to permanently increase reach and capacity
- Start with Level 0 (no bonus) and upgrade as you progress
- Mirror mode is excellent for symmetrical builds (houses, bridges)
- Wall/Floor modes make large flat surfaces trivial
- Creative mode gives full power - great for testing designs before survival
- Combine with WorldEdit for massive builds
