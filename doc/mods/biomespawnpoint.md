# Biome Spawn Point

**Version:** 2.3
**Category:** World Generation

## Description

Allows players to spawn in specific biomes when creating a new world. Configure which biomes players can spawn in, ensuring a desired starting environment.

## Key Features

- Configurable spawn biome selection
- Supports modded biomes
- Biome whitelist/blacklist
- Works with custom world types
- Simple configuration

## Configuration

Config file: `config/biomespawnpoint.toml`

Key settings:
- Spawn biome whitelist
- Biome weight/priority
- Fallback behavior

## Tips

- Great for modpacks with specific biome requirements
- Configure before world creation
- Some biomes may not be available without their mods
- Check compatibility with other spawn mods
