# Minecraft Forge

**Version:** 47.3.0
**Category:** Utility & Library

## Description
Minecraft Forge is the mod loader and API that enables all other mods to run. It provides a standardized way for mods to interact with Minecraft and with each other.

## Key Features
- Mod loading and lifecycle management
- Event system for mod interactions
- Registry system for blocks, items, entities
- Network packet handling
- Configuration system
- Mixin support for bytecode modification

## Configuration
- Main config: `config/forge-common.toml`
- Client config: `config/forge-client.toml`
- Server config: `config/forge-server.toml`

## Tips
- Always check Forge version compatibility when adding new mods
- Update Forge carefully - some mods may require specific versions
- Use `/forge mods` command in-game to list loaded mods
