# AI Improvements

**Version:** 1.x
**Category:** Performance

## Description
AI Improvements optimizes mob AI calculations, reducing CPU usage and improving performance, especially in areas with many entities.

## Key Features
- Optimized mob AI calculations
- Reduced CPU usage from entity AI
- Better performance with many mobs
- Configurable optimization levels
- Compatible with most entity mods

## Configuration
Config file: `config/aiimprovements.toml`

Key settings:
- `enabled`: Enable AI improvements (recommended: true)
- `optimizationLevel`: Level of AI optimization (1-3)
- `reducePathfinding`: Optimize pathfinding calculations
- `limitAIUpdates`: Limit AI update frequency

## Tips
- Particularly effective in mob farms
- Can significantly improve performance with many entities
- Test with your specific mob types
- Works well with Entity Culling for comprehensive optimization
