# AttributeFix

**Version:** 1.20.1-19.0.4
**Category:** Combat & Weapons

## Description
AttributeFix removes Minecraft's attribute limits, allowing mods to create more powerful items and effects. Essential for mods that exceed vanilla attribute caps.

## Key Features
- Removes attribute value caps
- Allows higher health, damage, speed values
- Compatible with most attribute mods
- Configurable attribute limits
- No performance impact

## Configuration
Config file: `config/attributefix.toml`
- `healthCap` - Maximum health value
- `damageCap` - Maximum damage value
- `speedCap` - Maximum speed value
- `armorCap` - Maximum armor value

## Tips
- Required for many mods with powerful items
- Be careful raising caps too high for balance
- Use with Apothic Attributes for full control
- Test balance after changing caps
