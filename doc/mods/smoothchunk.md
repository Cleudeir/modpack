# Smooth Chunk

**Version:** 1.x
**Category:** Performance

## Description
Smooth Chunk optimizes chunk loading and rendering to provide smoother gameplay. It reduces stuttering and lag spikes that occur when new chunks are loaded or rendered.

## Key Features
- Smooth chunk loading transitions
- Reduced stuttering during chunk loading
- Optimized chunk rendering pipeline
- Better performance during world exploration
- Minimal configuration needed

## Configuration
Config file: `config/smoothchunk.toml`

Key settings:
- `enabled`: Enable smooth chunk loading (recommended: true)
- `loadSpeed`: Speed of chunk loading (1-10)
- `renderOptimization`: Enable render optimizations

## Tips
- Works well with Chunk Sending mod
- Particularly effective when exploring new areas
- Can be combined with Fastload for faster world loading
- Adjust load speed based on your system's capabilities
