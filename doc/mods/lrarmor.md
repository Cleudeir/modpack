# LR Armor

**Version:** 1.20.1-2.1.2
**Category:** Combat & Weapons

## Description
LR Armor adds a custom armor system with layered protection, temperature effects, and durability mechanics. Provides more realistic armor behavior.

## Key Features
- Layered armor protection
- Temperature effects (hot/cold)
- Armor durability degradation
- Custom armor models
- Integration with Tough As Nails

## Configuration
Config file: `config/lrarmor.toml`
- `armorLayers` - Protection layer settings
- `temperatureEffects` - Temperature mechanics
- `durabilityRate` - Degradation speed
- `armorWeight` - Movement speed effects

## Tips
- Monitor temperature in extreme biomes
- Repair armor frequently to maintain protection
- Layer different armor types for balance
- Combine with Repair Kits for field maintenance
