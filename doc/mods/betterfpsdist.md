# BetterFpsDist

**Version:** 1.x
**Category:** Performance

## Description
BetterFpsDist optimizes FPS by adjusting rendering distance and quality based on performance. It dynamically adjusts settings to maintain smooth frame rates while preserving visual quality.

## Key Features
- Dynamic render distance adjustment
- FPS-based quality scaling
- Smooth performance transitions
- Minimal configuration needed
- Compatible with most rendering mods

## Configuration
Config file: `config/betterfpsdist.toml`

Key settings:
- `targetFps`: Target frame rate to maintain
- `minRenderDistance`: Minimum render distance allowed
- `maxRenderDistance`: Maximum render distance allowed
- `adjustmentSpeed`: How quickly settings adjust

## Tips
- Set targetFps to your monitor's refresh rate for smooth gameplay
- Works well with Embeddium for optimized rendering
- Monitor performance in different biomes and adjust if needed
- May conflict with manual render distance settings in other mods
