# Catalogue

**Version:** 1.x.x
**Category:** Quality of Life

## Description
Catalogue provides a clean interface for viewing all installed mods in your modpack. It shows mod information, version numbers, and other details in an organized list.

## Key Features
- List all installed mods
- Show mod version and author
- Mod description display
- Search and filter mods
- Copy mod info for support

## Configuration
Config file: `config/catalogue.toml`

Key settings:
- `showVersion` - Display mod versions
- `showDescription` - Show mod descriptions
- `sortBy` - Sort order for mod list
- `filterEnabled` - Enable search filtering

## Tips
- Use to quickly check mod versions
- Great for troubleshooting mod conflicts
- Copy info for bug reports
- Works with CurseForge and modpack launchers
