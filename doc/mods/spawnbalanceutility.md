# Spawn Balance Utility

**Version:** 1.20.1-1.2.0
**Category:** Mobs & Entities

## Description
Spawn Balance Utility helps balance mob spawning by adjusting spawn rates and weights. It ensures a more even distribution of mobs across biomes and prevents any single mob from dominating.

## Key Features
- Automatic spawn rate balancing
- Per-biome spawn adjustments
- Spawn weight normalization
- Compatible with other spawn mods
- Simple configuration interface
- Performance monitoring

## Configuration
Config file: `config/spawnbalanceutility.toml`

Key settings:
- Global spawn balance toggle
- Per-biome overrides
- Spawn weight limits
- Performance settings

## Tips
- Use alongside In Control for comprehensive spawn management
- Monitor mob counts with debug tools
- Adjust gradually to find the right balance
- Check for conflicts with other spawn mods
