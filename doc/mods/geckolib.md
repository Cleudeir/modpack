# GeckoLib

**Version:** 4.4.4
**Category:** Utility & Library

## Description
GeckoLib is an animation and model loading library for Minecraft mods. It enables complex animated models and is used by many mods for creatures, items, and blocks.

## Key Features
- Complex animation system
- Model loading from external files
- Particle effect support
- Sound synchronization with animations
- Armor and item rendering
- Block entity animations

## Configuration
- Config file: `config/geckolib.toml`
- Settings include animation performance options

## Tips
- Many creature mods depend on GeckoLib
- If animations look broken, update GeckoLib
- High entity counts may impact performance
