# WITs (Where Is This Structure)

**Version:** 1.1.0
**Category:** Exploration & Navigation

## Description
WITs (Where Is This Structure) helps players locate structures and points of interest in the world. It provides information about nearby structures and can guide players to them.

## Key Features
- Shows nearby structures on a minimap or HUD
- Provides coordinates and distance to structures
- Works with vanilla and modded structures
- Configurable detection range
- Can show structure boundaries
- Integration with JourneyMaps and other mapping mods

## Configuration
No config file found - uses default settings.

## Tips
- Press the default keybind (check controls) to toggle structure overlay
- Works best with mapping mods for visual guidance
- Some structures may not be detected if they're too far away
- Useful for finding dungeons, temples, villages, and modded structures
