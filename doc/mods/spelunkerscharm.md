# Spelunker's Charm

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A mod that adds specialized mining enchantments and tools for enhanced underground exploration. It provides charms and enchantments that improve mining efficiency and discovery.

## Key Features
- Mining-focused enchantments
- Charm items with mining bonuses
- Ore detection and highlighting
- Mining speed enhancements
- Integration with other mining mods

## Configuration
Config files are located in `config/spelunkerscharm/`. Key settings include:
- Enchantment levels and effects
- Charm item properties
- Ore detection ranges
- Mining speed multipliers

## Tips
- Combine enchantments for maximum mining efficiency
- Use charms for passive mining bonuses
- Ore detection works through walls at short range
- Upgrade tools with mining-specific enchantments
