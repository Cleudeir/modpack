# Nature's Compass

**Version:** Not Installed
**Category:** Exploration & Navigation

## Description
Nature's Compass is a mod that helps players find specific biomes in the world. It allows players to search for biomes and provides navigation assistance to locate them.

## Key Features
- Search for any biome in the game
- Provides coordinates and distance to biomes
- Works with vanilla and modded biomes
- Compass points toward selected biome
- Biome information display
- Compatible with mapping mods
