# TerraBlender

**Version:** 3.0.1.6
**Category:** Library / API

## Description

TerraBlender is a biome API that allows mods to add new biomes to the Overworld without conflicts. It provides a registry system for biome modifications, ensuring compatibility between multiple biome-adding mods.

## Key Features

- Biome registration API for mods
- Prevents biome conflicts between mods
- Manages biome placement and generation
- Required dependency for many biome mods
- Region-based biome system

## Configuration

Config file: `config/terrablender.toml`

Key settings:
- Biome weights
- Region configurations
- Debug settings

## Tips

- Required for many biome-adding mods
- Check compatibility with other worldgen mods
- Update regularly for best compatibility
- Some biome conflicts may require config adjustments
