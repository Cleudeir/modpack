# The Hordes

**Version:** 1.20.1-1.3.0
**Category:** Mobs & Entities

## Description
The Hordes adds periodic horde events where waves of zombies attack the player. These events provide challenging combat encounters with increasing difficulty.

## Key Features
- Timed horde events
- Multiple waves of increasing difficulty
- Unique horde mob variants
- Loot rewards for surviving
- Configurable event timing
- Visual and audio warnings before events

## Configuration
Config file: `config/hordes.toml`

Key settings:
- Event frequency
- Wave count and difficulty
- Mob type preferences
- Reward settings
- Warning system options

## Tips
- Prepare defenses before horde events
- Higher difficulties spawn more mobs per wave
- Building a fortified base helps survival
- Events can be triggered manually with commands
