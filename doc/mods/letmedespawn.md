# Let Me Despawn

**Version:** 1.20.1-1.0.0
**Category:** Mobs & Entities

## Description
Let Me Despawn allows mobs with equipment to despawn naturally, preventing entity buildup and lag. Mobs will despawn after a configurable time period regardless of equipment.

## Key Features
- Allows equipped mobs to despawn
- Configurable despawn timers
- Reduces entity lag
- Works with modded equipment
- Simple configuration

## Configuration
Config file: `config/letmedespawn.toml`

Key settings:
- Despawn timer length
- Equipment-based exceptions
- Enable/disable per mob type
- Performance mode

## Tips
- Helps reduce lag in areas with many mobs
- Can be combined with other despawn mods
- Adjust timers based on server performance
- Monitor entity counts for optimal settings
