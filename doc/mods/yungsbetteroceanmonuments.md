# YUNG's Better Ocean Monuments

**Version:** 3.0.4
**Category:** World Generation

## Description

Completely overhauls Ocean Monuments with larger, more complex structures. Features multiple floors, better guardians, improved loot, and more interesting interior layouts.

## Key Features

- Larger ocean monument structures
- Multiple floors and rooms
- Better guardian spawning
- Improved loot tables
- More interesting interior architecture

## Configuration

Config file: `config/yungsbetteroceanmonuments.toml`

Key settings:
- Monument size and complexity
- Guardian spawn rates
- Loot quality

## Tips

- Bring water breathing potions and good gear
- Monuments are much larger than vanilla
- Better loot makes the challenge worthwhile
- Clear rooms systematically to avoid getting overwhelmed
