# Design Decor

**Version:** 0.4.0b
**Category:** Building & Decoration

## Description
Design Decor adds modern furniture and decoration blocks to Minecraft. It provides stylish, contemporary furniture items perfect for modern home builds and urban-themed projects.

## Key Features
- Modern sofas and couches
- Kitchen appliances and counters
- Bathroom fixtures (sinks, toilets, bathtubs)
- Office furniture (desks, chairs)
- Shelving units and storage solutions
- Lighting fixtures
- Indoor plants and planters

## Configuration
Config file: `config/designdecor.toml`
- Enable/disable specific block categories
- Adjust placement settings

## Tips
- Ideal for modern or contemporary themed builds
- Works well with Chisel for additional block variants
- Consider pairing with Handcrafted for a mix of modern and classic furniture
