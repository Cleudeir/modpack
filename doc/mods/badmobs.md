# Bad Mobs

**Version:** 1.20.1-1.1.0
**Category:** Mobs & Entities

## Description
Bad Mobs allows you to remove unwanted mobs from the game. It provides a simple way to blacklist mobs from spawning, improving performance or gameplay balance.

## Key Features
- Simple mob blacklist system
- Remove any mob by name
- Works with modded mobs
- Performance improvements
- Easy configuration
- No impact on existing worlds

## Configuration
Config file: `config/badmobs.cfg`

Key settings:
- Mob blacklist entries
- Enable/disable toggle
- Log removed mob attempts
- Compatibility settings

## Tips
- Use entity IDs to blacklist mobs
- Removing too many mobs can affect ecosystem balance
- Check mod documentation for correct entity IDs
- Backup config before large changes
