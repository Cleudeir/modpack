# Just Zoom

**Version:** 1.x.x
**Category:** Quality of Life

## Description
Just Zoom adds a simple zoom function to Minecraft, allowing you to zoom in and out like an optical zoom. This is useful for scouting areas and seeing details from a distance.

## Key Features
- Smooth zoom in/out functionality
- Configurable zoom keybind
- Adjustable zoom levels
- Works in first and third person
- Lightweight and simple

## Configuration
Config file: `config/justzoom.toml`

Key settings:
- `zoomKey` - Keybind for zoom (default: C key)
- `zoomSpeed` - How fast zoom transitions
- `maxZoom` - Maximum zoom level
- `fovOverride` - Override FOV settings

## Tips
- Press and hold the zoom key to zoom
- Scroll while zooming to adjust level
- Works great for exploration and building
- No performance impact
- Alternative to OptiFine zoom
