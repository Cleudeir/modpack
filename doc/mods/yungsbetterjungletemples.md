# YUNG's Better Jungle Temples

**Version:** 2.0.5
**Category:** World Generation

## Description

Replaces vanilla jungle temples with larger, more intricate structures. Features multiple floors, hidden rooms, improved traps, and better loot that makes jungle exploration more rewarding.

## Key Features

- Larger jungle temple structures
- Multiple floors and hidden passages
- Improved trap mechanics
- Better loot tables
- Dense jungle-themed decorations

## Configuration

Config file: `config/yungsbetterjungletemples.toml`

Key settings:
- Structure spawn rate
- Loot quality
- Trap difficulty

## Tips

- Look for hidden rooms behind mossy stone
- The traps are more complex than vanilla
- Bring shears for hidden loot behind vines
- Good source of mid-game loot
