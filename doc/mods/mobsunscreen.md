# Mob Sunscreen

**Version:** 1.20.1-1.1.0
**Category:** Mobs & Entities

## Description
Mob Sunscreen prevents undead mobs from burning in sunlight. This makes daytime exploration more dangerous as zombies, skeletons, and other undead persist throughout the day.

## Key Features
- Prevents all undead mobs from burning in sunlight
- Configurable per mob type
- Works with modded undead mobs
- Simple configuration options
- No performance impact

## Configuration
Config file: `config/mobsunscreen.toml`

Key settings:
- Enable/disable per mob type
- Global toggle
- Compatibility mode for other mods

## Tips
- Daytime becomes significantly more dangerous
- Consider adding other difficulty mods for balance
- Works well with Zombie Awareness for tougher zombies
- Check compatibility with other mob mods
