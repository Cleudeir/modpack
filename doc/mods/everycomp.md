# Every Compat

**Version:** 2.6.74
**Category:** Building & Decoration

## Description
Every Compat is an compatibility mod that automatically generates wood variants for blocks from other mods. It ensures that mods with wood types get proper variants (stairs, slabs, etc.) for all installed wood types, reducing compatibility issues.

## Key Features
- Auto-generates wood variants for mod blocks
- Supports major wood type mods
- Adds missing block variants (stairs, slabs, fences)
- Compatible with many decoration mods
- Automatic resource pack generation

## Configuration
Config file: `config/everycomp.toml`
- Toggle specific block generation
- Configure wood type support

## Tips
- Essential for decoration-heavy modpacks
- No manual configuration needed in most cases
- Ensures consistent block variants across different mods
