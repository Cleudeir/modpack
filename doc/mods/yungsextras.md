# YUNG's Extras

**Version:** 4.0.3
**Category:** World Generation

## Description

Adds various small structures and features throughout the Overworld. Includes things like small dungeons, hidden loot caches, and other minor structures that add variety to exploration.

## Key Features

- Small dungeon structures
- Hidden loot caches
- Various decorative structures
- Adds variety to world generation
- Many configurable individual features

## Configuration

Config file: `config/yungsextras.toml`

Key settings:
- Enable/disable individual features
- Spawn rates
- Loot settings

## Tips

- Great for adding small details to the world
- Check config to customize which features appear
- Works well with other YUNG's mods
- Adds subtle variety without being overwhelming
