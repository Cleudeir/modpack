# Scorched Guns

**Version:** 1.20.1-1.1.5
**Category:** Combat & Weapons

## Description
Scorched Guns adds realistic firearms to Minecraft with detailed models, ammo systems, and ballistics. Features various gun types from pistols to assault rifles.

## Key Features
- Multiple firearm types (pistol, rifle, shotgun, sniper)
- Ammo crafting and loading system
- Realistic ballistics and bullet physics
- Recoil and spread mechanics
- Customizable attachments (scopes, silencers)

## Configuration
Config file: `config/scorchedguns.toml`
- `gunDamage` - Adjust weapon damage
- `bulletSpeed` - Modify projectile velocity
- `recoilIntensity` - Toggle/configure recoil
- `ammoConsumption` - Ammo usage rates

## Tips
- Craft ammo at a workbench before using guns
- Use scopes for long-range precision
- Combine with Trajectory Preview for better aim
- Guns degrade and need repair kits
