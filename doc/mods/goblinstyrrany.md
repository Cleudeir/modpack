# Goblin's Tyranny

**Version:** 2.3.1
**Category:** Mobs & Entities

## Description
Goblin's Tyranny adds goblin enemies, structures, and a progression system. Goblins spawn in custom structures and grow stronger as the player progresses through the game.

## Key Features
- Multiple goblin variants with different roles
- Custom goblin structures and dungeons
- Goblin raid events
- Loot tables and goblin-specific drops
- Goblins can use tools and weapons
- Scaling difficulty based on player progress

## Configuration
Config file: `config/goblinstyrrany.toml`

Key settings:
- Structure generation frequency
- Goblin spawn rates
- Difficulty scaling parameters
- Loot drop rates

## Tips
- Goblins can open doors—secure your base accordingly
- Higher-tier goblins appear as you progress
- Goblin structures contain valuable loot
- Raid events occur periodically—be prepared
