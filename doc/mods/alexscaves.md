# Alex's Caves

**Version:** 0.4.5
**Category:** Mobs & Entities

## Description
Alex's Caves adds several new cave biomes with unique mobs, blocks, and mechanics. Each cave biome has its own ecosystem with exclusive creatures and resources.

## Key Features
- 4 new cave biomes: Magnetic, Toxic, Primordial, and Abyssal
- 20+ new mobs unique to each biome
- New blocks, ores, and materials
- Custom armor sets and tools
- Unique music and ambient sounds
- Boss encounters in select biomes

## Configuration
Config file: `config/alexscaves.toml`

Key settings:
- Biome generation toggles
- Mob spawn rates
- Ore generation rates
- Performance settings for cave lighting

## Tips
- Bring appropriate gear for each biome—some have environmental hazards
- The Magnetic Caves require iron-based equipment
- Primordial Caves are dangerous; bring backup
- Check F3 for biome detection
