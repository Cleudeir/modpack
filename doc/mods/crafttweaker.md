# CraftTweaker

**Version:** 14.0.40
**Category:** Utility & Library

## Description
CraftTweaker is a recipe customization tool that allows modpack developers to modify recipes, remove items, and adjust game mechanics through ZenScript files.

## Key Features
- Recipe removal and addition
- Shaped/shapeless recipe creation
- Furnace recipe modification
- Ingredient manipulation
- Event listening
- JEI integration

## Configuration
- Scripts location: `scripts/` folder (`.zs` files)
- Config: `config/crafttweaker/`

## Tips
- Scripts load on game start - check logs for errors
- Use `/reload` to reload scripts without restarting
- Backup scripts before major changes
- Works alongside KubeJS for different use cases
