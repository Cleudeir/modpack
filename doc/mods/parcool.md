# ParCool

**Version:** 3.2.1.2-R
**Category:** Exploration & Navigation

## Description
ParCool adds parkour movement abilities to Minecraft, allowing players to perform acrobatic maneuvers like wall running, sliding, dodging, and climbing. It enhances movement with stamina-based abilities.

## Key Features
- Wall running (horizontal and vertical)
- Sliding and rolling
- Dodging and flipping
- Climbing poles and walls
- Cat leaps and vaulting
- Stamina system for ability usage
- Custom animations and camera effects
- Configurable ability toggles

## Configuration
Config file: `config/parcool-client.toml`

Key settings:
- `can_WallJump` - Enable wall jumping (default: false)
- `can_Dodge` - Enable dodging (default: true)
- `can_Slide` - Enable sliding (default: true)
- `can_Crawl` - Enable crawling (default: true)
- `stamina_hud_type` - HUD display (default: Light)
- `fast-run_modifier` - Sprint speed multiplier (default: 2.0)
- `dodge_cool_time` - Dodge cooldown (default: 11 ticks)
- `enable_animation` - Custom animations (default: true)

## Tips
- Stamina regenerates over time - manage it wisely
- Different abilities have different stamina costs
- Wall jumping is disabled by default - enable in config
- Creative mode grants infinite stamina
- Check keybinds in controls menu for ability keys
- Some abilities require sprinting first
