# Celestial Core

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A core library mod that provides essential APIs and utilities for other celestial-themed mods. It serves as a dependency for mods like Celestial Artifacts and other magical addons.

## Key Features
- Shared API for celestial-themed mods
- Common utilities and helper functions
- Event handling and registration systems
- Configuration management tools
- Compatibility layer between dependent mods

## Configuration
Config files are located in `config/celestialcore/`. Key settings include:
- API compatibility options
- Debug logging levels
- Integration settings
- Performance tuning options

## Tips
- This mod is required for Celestial Artifacts to function
- Keep it updated to ensure compatibility
- Check for updates before updating dependent mods
- Report issues to the celestial mod collection maintainers
