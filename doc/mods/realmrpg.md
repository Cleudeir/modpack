# Realm RPG

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A comprehensive RPG progression system that adds character classes, skill trees, and leveling mechanics. It transforms Minecraft into a full RPG experience with stats and abilities.

## Key Features
- Character class system with unique abilities
- Skill trees for each class
- Leveling and stat progression
- Class-specific equipment and abilities
- Integration with other RPG mods

## Configuration
Config files are located in `config/realmrpg/`. Key settings include:
- Class definitions and abilities
- Skill tree structures
- Leveling curves and stat gains
- Equipment restrictions and bonuses

## Tips
- Choose your class carefully as it defines your playstyle
- Invest in complementary skills for your build
- Some equipment is class-restricted
- Use class abilities strategically in combat
