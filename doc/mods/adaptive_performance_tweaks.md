# Adaptive Performance Tweaks

**Version:** 2.x
**Category:** Performance

## Description
Adaptive Performance Tweaks automatically adjusts game settings based on current performance, helping maintain smooth frame rates across different situations and hardware configurations.

## Key Features
- Automatic performance adjustment
- Dynamic quality scaling
- Real-time performance monitoring
- Minimal user configuration needed
- Adapts to different hardware capabilities

## Configuration
Config file: `config/adaptive_performance_tweaks.toml`

Key settings:
- `enabled`: Enable adaptive tweaks (recommended: true)
- `targetFps`: Target frame rate to maintain
- `adjustmentRate`: How quickly settings adjust
- `minQuality`: Minimum quality settings allowed

## Tips
- Great for users who don't want to manually adjust settings
- Works well with BetterFpsDist for comprehensive optimization
- Monitor performance to ensure it's adjusting appropriately
- Can be combined with other performance mods for best results
