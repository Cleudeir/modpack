# Inventory Profiles Next

**Version:** 1.10.x
**Category:** Quality of Life

## Description
Inventory Profiles Next adds powerful inventory sorting and management features. It automatically sorts items, stacks them, and provides tools to organize your inventory quickly.

## Key Features
- One-click inventory sorting
- Auto-stacking items
- Sort chests and containers
- Lock inventory slots
- Move matching items between inventories
- Configuration for sort order

## Configuration
Config file: `config/inventoryprofilesnext.json`

Key settings:
- `sortKey` - Keybind for sorting (default: R key in inventory)
- `moveMatching` - Move items matching clicked stack
- `enableAutoRefill` - Automatically refill tools
- `lockSlots` - Configure locked slots

## Tips
- Press `R` in inventory to sort
- Shift+R for advanced sorting options
- Lock slots you don't want sorted
- Works with most modded inventories
- Great for organizing chests quickly
