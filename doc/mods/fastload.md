# Fastload Reforged

**Version:** 1.x
**Category:** Performance

## Description
Fastload Reforged optimizes world loading and initialization, significantly reducing the time it takes to load into a world or server.

## Key Features
- Faster world loading times
- Optimized world initialization
- Reduced loading screen time
- Better startup performance
- Compatible with most mods

## Configuration
Config file: `config/fastload.toml`

Key settings:
- `enabled`: Enable fast loading (recommended: true)
- `optimizeInitialization`: Optimize world initialization
- `preloadChunks`: Preload chunks around spawn

## Tips
- Particularly effective with large modpacks
- Can reduce loading times by 50% or more
- Works well with Smooth Chunk for smooth transitions
- Test with your specific modpack for best results
