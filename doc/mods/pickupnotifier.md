# Pick Up Notifier

**Version:** 4.x.x
**Category:** Quality of Life

## Description
Pick Up Notifier displays a visual notification when you pick up items, showing what items you collected and their quantities. This is especially helpful with mods that add many items.

## Key Features
- Shows picked up items in a floating text
- Displays item count and icons
- Configurable display duration
- Works with modded items
- Adjustable position and appearance

## Configuration
Config file: `config/pickupnotifier.toml`

Key settings:
- `displayDuration` - How long notifications show
- `maxLines` - Maximum items shown at once
- `position` - Screen position of notifications
- `showInChat` - Also show in chat

## Tips
- Useful when mining to see what you collected
- Helps track modded item pickups
- Adjust duration if notifications disappear too fast
- Works in multiplayer
