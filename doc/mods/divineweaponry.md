# Divine Weaponry

**Version:** 1.20.1-2.4.1
**Category:** Combat & Weapons

## Description
Divine Weaponry adds new weapons, tools, and armor sets inspired by mythology and fantasy. Features unique materials and crafting recipes for progression.

## Key Features
- Multiple weapon types (swords, spears, hammers, etc.)
- New material tiers (mythril, orichalcum, etc.)
- Special abilities on legendary weapons
- Armor sets with set bonuses
- Compatible with Tough As Nails for temperature effects

## Configuration
Config file: `config/divineweaponry.toml`
- `weaponDamage` - Adjust weapon damage values
- `toolSpeed` - Modify tool efficiency
- `armorProtection` - Balance armor values
- `enableAbilities` - Toggle special abilities

## Tips
- Higher-tier materials require rare resources
- Legendary weapons have unique right-click abilities
- Pair with Better Combat for enhanced weapon animations
