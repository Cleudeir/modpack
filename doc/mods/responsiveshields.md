# Responsive Shields

**Version:** 1.20.1-2.1.0
**Category:** Combat & Weapons

## Description
Responsive Shields improves Minecraft's shield mechanics with better timing, visual feedback, and customization. Makes shield usage more intuitive and effective.

## Key Features
- Improved shield block timing
- Visual shield health indicator
- Customizable shield textures
- Better blocking feedback
- Compatible with modded shields

## Configuration
Config file: `config/responsiveshields.toml`
- `blockTiming` - Adjust block window
- `visualFeedback` - Toggle shield indicator
- `damageReduction` - Modify shield effectiveness
- `cooldownTime` - Shield cooldown duration

## Tips
- Time your blocks with attack animations
- Watch the shield indicator for block duration
- Pair with Better Combat for fluid combat flow
- Shield effectiveness varies by attack type
