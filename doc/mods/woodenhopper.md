# Wooden Hopper

**Version:** 1.6.0.1 (1.20.1)
**Category:** Technology & Automation / Early Game

## Description
Wooden Hopper is a simplified, early-game version of the vanilla hopper. It transfers items at a slower rate and has a smaller buffer, making it an accessible entry point for item transport automation before iron is readily available.

## Key Features
- **Early-game item transport** - Transfer items between containers
- **Slower transfer rate** - Designed as a weaker hopper alternative
- **Wooden material** - Crafted with wood instead of iron
- **Configurable** - Transfer speed and behavior can be adjusted

## Configuration
No dedicated config file was found in the config directory. The mod uses default settings with its built-in slower transfer rate.

## Tips
- Perfect for early-game farms before you have iron for vanilla hoppers
- Can be used in place of hoppers for low-throughput item sorting
- Works with all vanilla containers (chests, furnaces, droppers, etc.)
- Consider upgrading to vanilla hoppers once iron supply is stable
