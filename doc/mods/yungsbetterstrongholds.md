# YUNG's Better Strongholds

**Version:** 4.0.3
**Category:** World Generation

## Description

Overhauls Strongholds with much larger, more complex layouts. Features multiple wings, puzzle rooms, hidden passages, and better loot making the journey to the End more rewarding.

## Key Features

- Much larger stronghold structures
- Multiple wings and floors
- Puzzle and trap rooms
- Better loot distribution
- Improved library generation

## Configuration

Config file: `config/yungsbetterstrongholds.toml`

Key settings:
- Stronghold size and complexity
- Room variety
- Loot quality

## Tips

- Bring plenty of supplies for deep exploration
- Look for hidden rooms behind walls
- Libraries contain valuable books and enchanted items
- Essential for reaching the End
