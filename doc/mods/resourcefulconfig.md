# Resourceful Config

**Version:** 2.1.2
**Category:** Utility & Library

## Description
Resourceful Config is a configuration library that provides a modern config API. It supports both GUI-based and file-based configuration for mods.

## Key Features
- Modern config API
- In-game config editing
- Category and subcategory support
- Comment support
- Range and validation
- Multiple config formats

## Configuration
- Config files created by dependent mods appear in `config/`
- Use mod options screens to edit configs in-game

## Tips
- Used by many mods for configuration
- Configs auto-generate on first load
- Backup configs before major updates
