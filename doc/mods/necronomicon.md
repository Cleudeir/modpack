# Necronomicon

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A comprehensive magic documentation and spell system mod. It provides in-game documentation for magical spells, rituals, and mechanics, serving as a reference guide for magic mods.

## Key Features
- In-game documentation for spells and rituals
- Spell casting system with various components
- Ritual mechanics and requirements
- Magical theory and progression guides
- Integration with other magic mods

## Configuration
Config files are located in `config/necronomicon/`. Key settings include:
- Documentation display options
- Spell component availability
- Ritual requirements and effects
- Integration with other magic systems

## Tips
- Read the in-game guide thoroughly before attempting spells
- Start with basic spells before advancing to complex rituals
- Some spells require specific materials or conditions
- Use the index to quickly find specific information
