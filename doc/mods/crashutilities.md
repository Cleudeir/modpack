# Crash Utilities

**Version:** 8.1.4
**Category:** Utility & Library

## Description
Crash Utilities improves Minecraft's crash reporting by providing more detailed crash information and better error messages. Helps identify mod conflicts and issues.

## Key Features
- Enhanced crash reports
- Mod conflict detection
- Better error messages
- Crash report history
- Diagnostic information

## Configuration
- Config: `config/crashutilities.toml`

## Tips
- Keep enabled for better debugging
- Check `crash-reports/` folder for enhanced reports
- Useful for identifying problematic mod combinations
