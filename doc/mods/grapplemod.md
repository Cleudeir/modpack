# Grappling Hook Mod

**Version:** 1.8+1.20.1
**Category:** Exploration & Navigation

## Description
Grappling Hook Mod adds customizable grappling hooks to Minecraft. It allows players to throw hooks that latch onto blocks and pull them toward the hook location, enabling vertical and horizontal movement.

## Key Features
- Throw grappling hooks that latch onto blocks
- Pull player toward hook location
- Customizable rope length and physics
- Motorized hooks for powered movement
- Double hooks for advanced maneuvering
- Wall running enchantments
- Double jump enchantments
- Sliding mechanics

## Configuration
Config file: `config/grapplemod.toml`

Key settings:
- `options.grapplinghook.custom.rope.maxlen` - Maximum rope length (default: 30.0)
- `options.grapplinghook.custom.hookthrower.throwspeed` - Hook throw speed (default: 2.0)
- `options.grapplinghook.custom.hookthrower.reelin` - Reel in player (default: true)
- `options.grapplinghook.custom.motor.motor` - Enable motor (default: false)
- `options.grapplinghook.blocks.grapplingBlocks` - Blocks hook can latch to (default: any)
- `options.enchantments.wallrun` - Wall run enchantment settings
- `options.enchantments.doublejump` - Double jump enchantment settings

## Tips
- Craft grappling hooks at a smithing table
- Right-click to throw hook, shift to reel in
- Motorized hooks consume durability faster
- Wall run and double jump are enchantments (not abilities)
- Rope can be customized for different playstyles
- Hook affects entities by default - disable in config
