# YUNG's Better Witch Huts

**Version:** 3.0.3
**Category:** World Generation

## Description

Replaces vanilla witch huts with larger, more detailed structures. Features multiple rooms, better brewing stations, and improved loot that make witch huts more interesting to explore.

## Key Features

- Larger witch hut structures
- Multiple rooms and floors
- Better brewing equipment
- Improved loot tables
- More witch-themed decorations

## Configuration

Config file: `config/yungsbetterwitchhuts.toml`

Key settings:
- Structure spawn rate
- Loot quality
- Size adjustments

## Tips

- Huts are larger than vanilla - look around for extra rooms
- Good source of brewing ingredients
- Witches still spawn nearby
- Useful for setting up a base near witch drops
