# Eating Animation

**Version:** 1.x.x
**Category:** Quality of Life

## Description
Eating Animation adds visual animations when eating food in Minecraft. It shows the food being consumed in your hand, making eating more immersive and visual.

## Key Features
- Visual eating animation
- Food items shown being consumed
- Works with modded foods
- Smooth animation transitions
- First and third person support

## Configuration
Config file: `config/eatinganimation.toml`

Key settings:
- `enableAnimation` - Toggle eating animations
- `animationSpeed` - Speed of eating animation
- `showInFirstPerson` - Show in first person view
- `showInThirdPerson` - Show in third person view

## Tips
- Makes eating more immersive
- Works with most food items
- Great for screenshots and videos
- Disable if performance is affected
