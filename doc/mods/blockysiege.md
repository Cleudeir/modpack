# Blocky Siege

**Version:** 6.1.92
**Category:** Adventure & Dungeons

## Description
Blocky Siege adds siege defense gameplay to Minecraft with cannons, siege weapons, and defensive structures. Players can build and defend against waves of enemies using various siege equipment and fortifications.

## Key Features
- Cannons and siege weapons for offensive combat
- Defensive structures and fortifications
- Wave-based enemy attacks
- Destructible terrain and structures
- Various projectile types and ammunition
- Integration with base building mechanics

## Configuration
**Config file:** `config/blocky_siege.toml`

Key settings:
- `Cannon Damage` - Damage dealt by cannons - Default: 12.0
- Additional settings managed through mod's in-game configuration
- Compatible with Create mod for automated defenses
- Works with other combat and building mods

## Tips
- Build thick walls to withstand cannon fire
- Position cannons on elevated ground for better range
- Use different projectile types for various situations
- Repair defenses between waves
- Combine with Create mod for automated siege weapons
- Stockpile ammunition before defending against waves
