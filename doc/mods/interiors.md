# Interiors

**Version:** 0.5.3
**Category:** Building & Decoration

## Description
Interiors adds interior decoration blocks focused on creating detailed, realistic indoor spaces. It provides a variety of blocks for building complete room interiors, from walls to furniture.

## Key Features
- Wall panels and wallpaper
- Floor tiles and carpeting
- Ceiling decorations
- Door and window frames
- Shelving units
- Lighting fixtures
- Decorative trim and molding

## Configuration
Config file: `config/interiors.toml`
- Toggle specific block categories
- Adjust placement behaviors

## Tips
- Excellent for creating detailed room interiors
- Works well with other furniture mods for complete builds
- Great for roleplay or adventure map building
