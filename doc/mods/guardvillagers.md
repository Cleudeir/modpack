# Guard Villagers

**Version:** 1.20.1-1.1.0
**Category:** Mobs & Entities

## Description
Guard Villagers adds trainable guard NPCs to villages that actively protect villagers and players from hostile mobs. Guards can be equipped and assigned to patrol routes.

## Key Features
- Multiple guard types (melee, archer, knight)
- Guards actively fight hostile mobs
- Equipment can be given to guards
- Guards protect villagers during raids
- Configurable guard spawn rates
- Guards can be commanded with simple interactions

## Configuration
Config file: `config/guardvillagers.toml`

Key settings:
- Guard spawn frequency per village
- Guard health and damage values
- Equipment compatibility settings
- Guard behavior priorities

## Tips
- Equip guards with better gear for tougher encounters
- Guards will follow players within a certain range
- Iron golems and guards work well together
- Guards respawn after death if the village is active
