# More Bows

**Version:** 1.20.1-1.1.2
**Category:** Combat & Weapons

## Description
More Bows adds additional bow types with unique properties and behaviors. Each bow has different draw speeds, damage, and special arrow interactions.

## Key Features
- Longbow - Slow draw, high damage
- Shortbow - Fast draw, lower damage
- Crossbow variants with bolt types
- Compound bow with adjustable draw
- Custom arrow types (explosive,pectral, etc.)

## Configuration
Config file: `config/morebows.toml`
- `bowStats` - Individual bow statistics
- `arrowDamage` - Arrow damage modifiers
- `drawSpeed` - Draw speed multipliers
- `enchantability` - Enchantment compatibility

## Tips
- Longbows excel at sniping from distance
- Shortbows work better for close combat
- Use appropriate arrows for each bow type
- Enchant for power and infinity when possible
