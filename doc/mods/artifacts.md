# Artifacts

**Version:** 1.20.1-3.0.0
**Category:** Combat & Weapons

## Description
Artifacts adds over 20 unique trinkets and accessories that provide special abilities. These items can be found in dungeon loot or crafted, offering various utility and combat enhancements.

## Key Features
- Flamingo Flippers - Enhanced swimming speed
- Pocket Piston - Push blocks with right-click
- Crystal Heart - Bonus health regeneration
- Kurtz's Medkit - Emergency healing item
- 20+ unique trinkets with various effects

## Configuration
Config file: `config/artifacts.toml`
- `enable` - Enable/disable specific artifacts
- `dungeonLoot` - Enable dungeon loot spawning
- `craftingRecipes` - Enable crafting recipes

## Tips
- Most artifacts require Curios API to function
- Check dungeon chests for rare artifacts
- Some artifacts have cooldowns - manage usage carefully
