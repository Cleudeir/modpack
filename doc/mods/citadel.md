# Citadel

**Version:** 2.6.0
**Category:** Utility & Library

## Description
Citadel is a library mod primarily used by Alex's Mobs and other mods from the same developer. It provides shared utilities and APIs for entity management and rendering.

## Key Features
- Entity registration helpers
- Custom entity rendering APIs
- Animation system utilities
- Configuration helpers
- Network packet handling

## Configuration
No direct configuration - this is a dependency library.

## Tips
- Required by Alex's Mobs and related mods
- Keep updated when updating dependent mods
- Safe to remove if no dependent mods are installed
