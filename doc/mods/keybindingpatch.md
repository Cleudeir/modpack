# Key Binding Patch

**Version:** 4.x.x
**Category:** Quality of Life

## Description
Key Binding Patch helps resolve keybinding conflicts by automatically rebinding duplicate keys or providing tools to manage them. This is essential for modpacks with many mods that add keybinds.

## Key Features
- Detects keybinding conflicts
- Automatic conflict resolution
- Manual conflict management
- Visual conflict indicators
- Priority system for keybinds

## Configuration
Config file: `config/keybindingpatch.toml`

Key settings:
- `autoResolve` - Automatically resolve conflicts
- `priority` - Keybind priority ordering
- `notification` - Show conflict notifications
- `whitelist` - Keybinds to ignore

## Tips
- Install alongside Controlling for best results
- Check for conflicts when adding new mods
- Use priority to ensure important keybinds work
- Notifications help identify issues quickly
