# Searchables

**Version:** 1.x.x
**Category:** Quality of Life

## Description
Searchables enhances search functionality across Minecraft, adding better search capabilities to inventories, JEI, and other mod interfaces. It improves how you find items and information.

## Key Features
- Enhanced search in inventories
- Better JEI integration
- Fuzzy search support
- Search history
- Configurable search behavior

## Configuration
Config file: `config/searchables.toml`

Key settings:
- `fuzzySearch` - Enable fuzzy matching
- `searchHistory` - Save search history
- `caseSensitive` - Case sensitive search
- `maxResults` - Maximum search results

## Tips
- Works with JEI for better item searching
- Use partial names for fuzzy matching
- Search history helps repeat searches
- Great for modpacks with many items
