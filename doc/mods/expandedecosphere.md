# Expanded Ecosphere

**Version:** 3.2.4
**Category:** World Generation

## Description

Adds many new biomes and terrain features to the Overworld. Includes new forest types, mountain biomes, and unique terrain generation that greatly expands world variety.

## Key Features

- 20+ new biomes
- Unique terrain generation
- New trees, plants, and vegetation
- Improved biome distribution
- Works with TerraBlender for biome placement

## Configuration

Config file: `config/expanded_ecosphere.toml`

Key settings:
- Biome weights
- Terrain generation settings
- Feature spawn rates

## Tips

- Greatly expands exploration variety
- Some biomes are rare - explore widely to find them
- Works well with other biome mods
- Check for biome conflicts with other mods
