# FerriteCore

**Version:** 5.x
**Category:** Performance

## Description
FerriteCore is a memory optimization mod that significantly reduces RAM usage in Minecraft. It works by optimizing how Minecraft stores block states and other data structures in memory.

## Key Features
- Reduces memory usage by 50% or more
- Optimizes block state storage
- Improves performance in large worlds
- Minimal configuration required
- Compatible with most mods

## Configuration
Config file: `config/ferritecore.toml`

Key settings:
- `blockStateCacheSize`: Adjust block state cache size
- `memoryOptimizationLevel`: Level of memory optimization (0-3)

## Tips
- Combine with ModernFix for maximum memory savings
- Particularly effective in modpacks with many custom blocks
- No performance overhead - pure memory optimization
- Works automatically with minimal configuration needed
