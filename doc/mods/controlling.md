# Controlling

**Version:** 12.x.x
**Category:** Quality of Life

## Description
Controlling provides a better interface for managing keybindings, making it easier to find, search, and organize your controls. It replaces the vanilla keybinding screen with a more user-friendly one.

## Key Features
- Searchable keybinding list
- Visual key conflict detection
- Category organization
- Export/import keybindings
- Easy key rebinding interface

## Configuration
Config file: `config/controlling.json`

Key settings:
- `searchEnabled` - Enable search bar
- `showConflicts` - Highlight conflicting keys
- `categoryView` - Group by category
- `compactMode` - Use compact display

## Tips
- Use the search bar to find specific keybinds
- Red highlights indicate key conflicts
- Great for modpacks with many keybinds
- Export your settings to backup them
- Press the configured key to open the menu
