# Repair Kits

**Version:** 1.20.1-1.0.4
**Category:** Combat & Weapons

## Description
Repair Kits allow you to repair tools and armor in the field without an anvil. Craftable items that provide convenience for adventuring.

## Key Features
- Field repair without anvil
- Different kit tiers (basic, advanced, elite)
- Works on tools and armor
- Configurable repair amounts
- Stackable items

## Configuration
Config file: `config/repairkits.toml`
- `repairAmount` - Base repair percentage
- `kitTiers` - Tier-specific values
- `cooldownTime` - Repair cooldown
- `materialCost` - Crafting material costs

## Tips
- Always carry basic repair kits on adventures
- Advanced kits work better on high-tier gear
- Combine with LR Armor for equipment maintenance
- Craft in bulk for long expeditions
