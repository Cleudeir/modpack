# Nameless Trinkets

**Version:** 1.20.1-2.1.0
**Category:** Combat & Weapons

## Description
Nameless Trinkets expands on the trinket system with additional accessories that provide utility and combat bonuses. Features both useful and intentionally cursed items for variety.

## Key Features
- Lucky Clover - Increased luck for loot drops
- Golden Hook - Faster fishing
- Lucky Scarf - Better enchantment odds
- Various cursed trinkets with trade-offs
- Compatibility with Curios API

## Configuration
Config file: `config/namelesstrinkets.toml`
- `enableItems` - Toggle individual trinkets
- `lootTables` - Modify loot generation
- `curseChance` - Probability of cursed variants

## Tips
- Some "cursed" trinkets have hidden benefits
- Combine with other trinket mods for more variety
- Check both positive and negative effects before equipping
