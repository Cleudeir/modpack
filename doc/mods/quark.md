# Quark

**Version:** 4.0-460
**Category:** Building & Decoration

## Description
Quark is a massive Vanilla+ mod that adds hundreds of new blocks, items, and mechanics to Minecraft. It's designed to feel like vanilla content, with many new building blocks, decorative items, and quality-of-life features.

## Key Features
- New wood types and variants
- Decorative blocks (brick variants, stones)
- Building blocks (new stairs, slabs, walls)
- Furniture items
- Quality-of-life mechanics
- Inventory management improvements
- New mobs and biomes

## Configuration
Config file: `config/quark.toml`
- Enable/disable specific features
- Highly customizable

## Tips
- Very large mod - configure individual features to avoid conflicts
- Quark Oddities adds additional quirky features
- Excellent for expanding vanilla building options
- Check for conflicts with other mods during configuration
