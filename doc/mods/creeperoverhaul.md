# Creeper Overhaul

**Version:** 3.0.3
**Category:** Mobs & Entities

## Description
Creeper Overhaul replaces vanilla creepers with biome-specific variants that have unique appearances and behaviors. Each variant blends into its environment and may have different explosion characteristics.

## Key Features
- 13+ biome-specific creeper variants
- Each variant has a unique skin matching its biome
- Some variants have modified explosion behavior
- Better mob integration with world generation
- Configurable spawn rules per variant
- Works with most shader packs

## Configuration
Config file: `config/creeperoverhaul.toml`

Key settings:
- Enable/disable individual variants
- Spawn weight per biome variant
- Explosion power overrides
- Sound customization

## Tips
- Swamp creepers have reduced explosion power
- Jungle creepers are harder to spot due to camouflage
- Desert creepers can spawn more frequently in sandy biomes
- Use F3 to identify variant types
