# Puffish Skills

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A skill tree and progression system that adds RPG-style skill trees with customizable abilities. Players unlock and upgrade skills through gameplay, allowing for diverse character builds and playstyles.

## Key Features
- Customizable skill trees with branching paths
- XP-based skill unlocking and upgrading
- Support for multiple skill trees
- Configurable skill effects and requirements
- Integration with other progression mods

## Configuration
Config files are located in `config/puffishskills/`. Key settings include:
- Skill tree definitions and layouts
- XP requirements per skill level
- Skill effect parameters
- Integration options with other mods

## Tips
- Plan your skill tree build before investing points
- Some skills have prerequisites - check the tree structure
- XP earned from various activities can be configured
- Backup your config before making major changes
