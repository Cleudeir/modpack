# Resourceful Lib

**Version:** 2.1.29
**Category:** Utility & Library

## Description
Resourceful Lib is a library focused on resource management and common utilities. It provides APIs for data generation, tags, and resource handling.

## Key Features
- Resource/data management
- Tag creation and management
- Data generation helpers
- Recipe utilities
- Configuration helpers

## Configuration
No direct configuration - this is a dependency library.

## Tips
- Required by Resourceful Config and other mods
- Helps with data pack creation
- Safe to keep installed generally
