# Log Begone

**Version:** 1.0.8
**Category:** Utility & Library

## Description
Log Begone filters out annoying or repetitive log messages to keep your game logs clean and readable. Essential for modpacks with many mods.

## Key Features
- Log message filtering
- Regex pattern matching
- Custom filter rules
- Performance improvement
- Cleaner log files

## Configuration
- Config: `config/logbegone.toml`
- Add patterns to filter specific messages

## Tips
- Add annoying log patterns to filter list
- Use regex for complex pattern matching
- Don't filter error messages you might need
- Helps with log file size management
