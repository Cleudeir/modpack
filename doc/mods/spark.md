# Spark

**Version:** 1.10.53
**Category:** Utility & Library

## Description
Spark is a performance profiler for Minecraft that helps identify lag sources, memory issues, and performance bottlenecks. Essential for debugging server and client performance.

## Key Features
- CPU profiling
- Memory profiling
- TPS monitoring
- Entity tick tracking
- Chunk loading analysis
- Web-based viewer

## Configuration
- Command: `/spark profiler`
- Config: `config/spark/`

## Tips
- Use `/spark tps` to check server performance
- Run profiler during lag spikes for best results
- Share profiler results via web viewer for help
- Lightweight when not actively profiling
