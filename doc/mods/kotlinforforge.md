# Kotlin for Forge

**Version:** 4.11.0
**Category:** Utility & Library

## Description
Kotlin for Forge adds Kotlin language support to Minecraft Forge. It allows mods written in Kotlin to run on the Forge mod loader.

## Key Features
- Kotlin standard library
- Coroutines support
- Forge Kotlin extensions
- Language initialization
- Metadata support

## Configuration
No direct configuration - this is a language support library.

## Tips
- Required by mods written in Kotlin
- Safe to keep installed even without Kotlin mods
- Update when updating Forge or Kotlin-dependent mods
