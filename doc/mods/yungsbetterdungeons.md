# YUNG's Better Dungeons

**Version:** 4.0.4
**Category:** World Generation

## Description

Completely overhauls vanilla dungeons with larger, more complex rooms, multiple floors, and themed decorations. Each mob type gets its own dungeon style with unique layouts and traps.

## Key Features

- Multi-room dungeons with multiple floors
- Themed dungeons per mob type (skeleton, zombie, spider, cave spider)
- Improved mob spawner placement
- Better loot distribution
- More challenging combat encounters

## Configuration

Config file: `config/yungsbetterdungeons.toml`

Key settings:
- Dungeon spawn frequency
- Size and complexity settings
- Loot quality adjustments

## Tips

- Each mob type has a distinct dungeon style
- Clear rooms methodically - mobs can come from multiple directions
- Look for hidden loot rooms
- Higher difficulty than vanilla dungeons
