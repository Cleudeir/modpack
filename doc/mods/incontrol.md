# In Control

**Version:** 1.20.1-6.0.0
**Category:** Mobs & Entities

## Description
In Control gives server administrators and modpack creators fine-grained control over mob spawning. It allows custom rules for when, where, and how mobs spawn.

## Key Features
- Custom spawn rules based on conditions
- Biome, dimension, and time-based spawning
- Spawn rate multipliers
- Mob type restrictions
- Potential-based spawn control
- JSON-based configuration

## Configuration
Config file: `config/incontrol.json`

Key settings:
- Spawn rule definitions
- Biome restrictions
- Dimension-specific rules
- Time-based spawning
- Light level requirements

## Tips
- Use potential rules to control spawn density
- Combine with Spawn Balance Utility for optimal results
- Test rules in creative mode first
- Back up config before major changes
