# Rhino

**Version:** 2001.2.3-build.6
**Category:** Utility & Library

## Description
Rhino is a JavaScript engine that powers KubeJS. It provides the runtime environment for executing JavaScript scripts within Minecraft.

## Key Features
- JavaScript runtime engine
- ES6+ support
- Optimized for Minecraft
- Memory management
- Error handling

## Configuration
No direct configuration - this is a core dependency for KubeJS.

## Tips
- Required by KubeJS - do not remove
- If KubeJS scripts fail, check Rhino version
- Updates may include performance improvements
