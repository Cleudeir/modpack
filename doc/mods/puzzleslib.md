# Puzzles Lib

**Version:** 8.1.22
**Category:** Utility & Library

## Description
Puzzles Lib is a multi-purpose library mod providing utilities for configuration, networking, and game mechanics. Used by various mods for common functionality.

## Key Features
- Configuration management
- Network packet handling
- Recipe utilities
- Command helpers
- Event handling
- Registry abstractions

## Configuration
No direct configuration - this is a dependency library.

## Tips
- Required by multiple mods in this pack
- Provides stable APIs for mod interactions
