# Trajectory Preview

**Version:** 1.20.1-1.0.3
**Category:** Combat & Weapons

## Description
Trajectory Preview shows the predicted flight path of projectiles like arrows and thrown items. Helps with aiming and understanding projectile physics.

## Key Features
- Visual trajectory line for projectiles
- Works with bows, crossbows, and tridents
- Adjustable line visibility and color
- Server-side calculation for accuracy
- Minimal performance impact

## Configuration
Config file: `config/trajectorypreview.toml`
- `lineColor` - Trajectory line color
- `lineLength` - Maximum visible distance
- `showOnSneak` - Only show when sneaking
- `particleEffects` - Enable particle trail

## Tips
- Useful for learning projectile physics
- Disable in competitive PvP for fairness
- Combine with gun mods for better aiming
- Practice with different draw strengths
