# Incendium

**Version:** 5.3.5
**Category:** World Generation

## Description

A complete Nether overhaul that adds new biomes, structures, and terrain generation to the Nether dimension. Transforms the Nether from a flat wasteland into a diverse and dangerous dimension.

## Key Features

- New Nether biomes with unique terrain
- New structures and dungeons
- Improved mob spawning
- Better terrain generation
- New Nether-specific resources

## Configuration

Config file: `config/incendium.toml`

Key settings:
- Biome generation weights
- Structure spawn rates
- Mob spawning rules

## Tips

- The Nether is much more varied now - explore different biomes
- New structures contain valuable loot
- Watch out for new mob variants
- Greatly improves Nether exploration
