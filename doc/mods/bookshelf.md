# Bookshelf

**Version:** 20.2.13
**Category:** Utility & Library

## Description
Bookshelf is a library mod that provides common utilities and APIs for other mods. It includes helper functions for configurations, networking, and game mechanics.

## Key Features
- Configuration utilities
- Network packet helpers
- Command registration
- Recipe helpers
- Enchantment utilities
- Tool/armor attribute helpers

## Configuration
No direct configuration - this is a dependency library.

## Tips
- Required by mods like Enchantment Descriptions and Pick Up Notifier
- Safe to keep installed even if dependent mods are removed
- Check version compatibility when updating
