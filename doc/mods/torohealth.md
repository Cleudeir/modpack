# ToroHealth

**Version:** 1.20.1-4.0.3
**Category:** Combat & Weapons

## Description
ToroHealth provides detailed health information for mobs including health bars, damage taken, and status effects. Offers customizable UI for mob information display.

## Key Features
- Detailed health bar with numeric values
- Damage taken tracking
- Status effect display
- Multiple UI styles (minimal, detailed, etc.)
- Works with modded mobs

## Configuration
Config file: `config/torohealth.toml`
- `uiStyle` - Health bar appearance
- `showNumbers` - Display numeric health
- `showEffects` - Show active effects
- `position` - UI position on screen

## Tips
- Great for boss fights and modded content
- Use with Damage Indicator for comprehensive info
- Customize UI to match your pack's style
- Some mob types may need manual configuration
