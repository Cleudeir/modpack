# Lost Cities

**Version:** Not installed
**Category:** World Generation

## Description

Lost Cities generates post-apocalyptic city ruins throughout the world. Features massive city structures with ruined buildings, streets, and underground areas to explore.

## Key Features

- Massive city ruins generation
- Ruined buildings and streets
- Underground metro systems
- High-rise buildings to explore
- Post-apocalyptic atmosphere

## Configuration

Config file: `config/lostcities.toml`

Key settings:
- City generation frequency
- Building height and density
- Street generation

## Tips

- Cities are massive - bring supplies for long exploration
- Look for loot in buildings and underground
- Great for base building in ruins
- Some buildings have multiple floors to explore
