# Create Stuff & Additions

**Version:** 2.0.4a (1.20.1)
**Category:** Technology & Automation

## Description
Create Stuff & Additions expands Create with additional tools, weapons, armor, and utility blocks. It adds Create-themed equipment and machines that complement the base mod's mechanical systems.

## Key Features
- **Create-themed Tools** - Copper and brass pickaxes, axes, shovels, and swords
- **Rose Quartz Equipment** - Rose quartz sword and tools with unique properties
- **Brass Tools** - Higher-tier brass equipment
- **Additional Blocks** - Extra decorative and functional blocks for Create builds
- **New Recipes** - Expanded crafting options using Create components

## Configuration
This mod has limited configuration options. No dedicated config file was found - it primarily adds content through recipes and items rather than configurable mechanics.

## Tips
- Copper tools are early-game; brass and rose quartz are upgrades
- Compatible with Create and Create Crafts & Additions
- Tool stats follow vanilla progression tiers
- Check JEI for new recipes added by this mod
