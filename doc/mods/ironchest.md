# Iron Chests

**Version:** 14.4.4 (1.20.1)
**Category:** Technology & Automation / Storage

## Description
Iron Chests adds upgraded storage containers with increased capacity beyond vanilla chests. Available in multiple tiers from copper to diamond, each tier provides more storage slots in a single block, reducing the space needed for item storage.

## Key Features
- **Copper Chest** - 27 slots (same as vanilla, but upgradeable path)
- **Iron Chest** - 54 slots (double chest in one block)
- **Gold Chest** - 72 slots
- **Diamond Chest** - 108 slots
- **Obsidian Chest** - 108 slots (blast resistant)
- **Crystal Chest** - 108 slots (transparent, can see items)
- **Upgrade system** - Upgrade chests in-place with upgrade kits

## Configuration
No dedicated config file found. Iron Chests typically uses default slot counts and can be configured via the mod's internal settings.

## Tips
- Upgrade chests in-place by right-clicking with the upgrade item
- Crystal chests are great for display/visual sorting systems
- Obsidian chests survive explosions - use for valuable storage
- Chests can be pushed by pistons (configurable)
- Works with hoppers and Create's mechanical arms for automation
