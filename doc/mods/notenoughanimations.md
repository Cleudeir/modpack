# Not Enough Animations

**Version:** 1.x.x
**Category:** Quality of Life

## Description
Not Enough Animations improves first-person animations, making them more realistic and visible. You can see your arms, items, and actions in first-person view like in many modern games.

## Key Features
- First-person arm animations
- Visible items in hand
- Eating and drinking animations
- Tool use animations
- Configurable animation styles

## Configuration
Config file: `config/notenoughanimations.toml`

Key settings:
- `firstPersonArms` - Show arms in first person
- `eatingAnimation` - Enable eating animations
- `toolAnimation` - Show tool use animations
- `sneakAnimation` - Enable sneak animations

## Tips
- Makes first-person feel more immersive
- Great for roleplay and screenshots
- Disable if animations feel distracting
- Works with most modded items
