# Apothic Attributes

**Version:** 1.20.1-1.2.0
**Category:** Combat & Weapons

## Description
Apothic Attributes extends Minecraft's attribute system with new stats and modifiers. Provides fine-grained control over combat mechanics and item properties.

## Key Features
- New attributes (crit chance, lifesteal, etc.)
- Item attribute modifiers
- Potion effect attributes
- Configurable stat ranges
- Compatibility with other attribute mods

## Configuration
Config file: `config/apothic_attributes.toml`
- `attributeRanges` - Min/max values
- `modifierSources` - Attribute sources
- `itemAttributes` - Item-specific modifiers
- `potionAttributes` - Potion effect modifiers

## Tips
- Combine with AttributeFix for maximum flexibility
- Use for custom RPG-like stat systems
- Balance attributes carefully for gameplay
- Works well with weapon mods for custom stats
