# Dungeons Arise

**Version:** 2.1.58
**Category:** World Generation

## Description

Dungeons Arise adds large, detailed dungeon structures throughout the Overworld. These are multi-room, explorable dungeons with loot, traps, and mobs that provide challenging combat encounters.

## Key Features

- 20+ unique large-scale dungeon structures
- Detailed interiors with multiple rooms and floors
- Treasure rooms with valuable loot
- Traps, puzzles, and mob spawners
- Structures spawn in various biomes

## Configuration

Config file: `config/dungeons_arise-common.toml`

Key settings:
- Structure spawn frequency
- Individual structure enable/disable
- Loot table adjustments

## Tips

- Bring good gear - these dungeons are challenging
- Look for the structures from a distance, they are very large
- Clear rooms carefully to avoid traps
- Some dungeons have hidden rooms with better loot
