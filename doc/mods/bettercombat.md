# Better Combat

**Version:** 1.8.6
**Category:** Combat & Weapons

## Description
Better Combat overhauls Minecraft's combat system with sweeping attacks, directional swings, and weapon-specific animations. It makes melee combat feel more dynamic and responsive.

## Key Features
- Directional attack swings based on mouse movement
- Sweeping attacks for swords and axes
- Weapon-specific attack animations and reach distances
- Hitbox improvements for more accurate hit detection
- Configurable attack speed and damage modifiers

## Configuration
Config file: `config/bettercombat.toml`
- `attackReach` - Base reach distance (default: 3.0)
- `sweepingDamage` - Sweeping attack damage multiplier
- `animationStyle` - Attack animation style (default/realistic)

## Tips
- Combine with weapon mods for unique attack styles per weapon
- Increase reach slightly for large weapons like greatswords
- Disable sweeping for PvP servers if it creates unfair advantages
