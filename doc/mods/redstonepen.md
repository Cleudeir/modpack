# Redstone Pen

**Version:** 1.3.20 (1.20.1 Forge)
**Category:** Technology & Automation / Redstone

## Description
Redstone Pen adds a pen-like tool for drawing and placing Redstone dust in creative patterns. It allows players to sketch Redstone circuits directly onto surfaces, making complex Redstone builds faster and more intuitive.

## Key Features
- **Redstone Pen Tool** - Draw Redstone lines on surfaces
- **Creative mode drawing** - Sketch circuits like drawing on paper
- **Surface placement** - Place Redstone on walls, floors, and ceilings
- **Pattern-based circuits** - Create complex Redstone patterns quickly

## Configuration
No dedicated config file found in the config directory. The mod uses its default settings for pen behavior.

## Tips
- Works best in Creative mode for circuit design and testing
- Great for prototyping Redstone builds before survival implementation
- Can speed up Redstone-heavy projects significantly
- The pen item can be found in the creative inventory
- Consider using alongside other Redstone mods for complex automation
