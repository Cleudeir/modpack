# Damage Indicator

**Version:** 1.20.1-1.14.0
**Category:** Combat & Weapons

## Description
Damage Indicator adds health bars above mobs showing their current health. Provides detailed information about mob health, armor, and status effects.

## Key Features
- Health bar above mobs
- Armor and absorption display
- Status effect indicators
- Health change animations
- Multiple display styles

## Configuration
Config file: `config/damageindicator.toml`
- `displayStyle` - Health bar appearance
- `showArmor` - Display armor values
- `showEffects` - Show status effects
- `range` - Maximum display distance

## Tips
- Helps track boss health during fights
- Useful for understanding mob toughness
- Disable for hardcore/immersive mode
- Works well with ToroHealth for more details
