# Character Leveling

**Version:** 1.0.0
**Category:** Magic & RPG

## Description
A mod that adds character leveling with stat allocation and progression. Players earn experience points and allocate stat points to improve their character's abilities.

## Key Features
- Experience-based character leveling
- Stat point allocation system
- Multiple stat categories (Strength, Agility, etc.)
- Level-based passive bonuses
- Integration with other RPG mods

## Configuration
Config files are located in `config/characterleveling/`. Key settings include:
- XP gain rates from different sources
- Stat point allocation limits
- Stat effect multipliers
- Level scaling parameters

## Tips
- Plan your stat allocation before investing points
- Some stats have diminishing returns at high levels
- Respec options may be available through items or commands
- Combine with other mods for enhanced RPG experience
