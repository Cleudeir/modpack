# Mouse Tweaks

**Version:** 2.18.x
**Category:** Quality of Life

## Description
Mouse Tweaks enhances mouse controls in inventories, allowing you to move items more efficiently with various mouse gestures and click combinations.

## Key Features
- Scroll wheel item movement
- Right-click dragging to distribute items
- Left-click dragging to move items
- Configurable behavior for each action
- Works with most inventory types

## Configuration
Config file: `config/mousetweaks.cfg`

Key settings:
- `LMBTweak` - Left mouse button tweak behavior
- `RMBTweak` - Right mouse button tweak behavior
- `WheelTweak` - Scroll wheel behavior
- `EnableSorting` - Enable inventory sorting

## Tips
- Scroll wheel moves items one at a time
- Right-click drag distributes items evenly
- Left-click drag moves entire stacks
- Disable in config if conflicts occur
- Great for organizing chests and crafting
