# Amendments

**Version:** 1.2.10
**Category:** Building & Decoration

## Description
Amendments enhances existing vanilla blocks with new functionality and variations. It makes the game feel more polished by adding missing features and small improvements to vanilla Minecraft blocks.

## Key Features
- Stacked items (pots, candles, skulls)
- Cauter and cauldron improvements
- Wall-mounted signs
- Ladder and fence gate improvements
- New stair and slab variants for existing blocks
- Improved block placement and rotation
- Book shelf improvements

## Configuration
Config file: `config/amendments.toml`
- Toggle specific amendments on/off
- Adjust placement and interaction behaviors

## Tips
- Essential for vanilla builders who want more block placement options
- Wall signs are particularly useful for labeling builds
- Complements Supplementaries by adding small but useful vanilla enhancements
