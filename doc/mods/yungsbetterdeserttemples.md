# YUNG's Better Desert Temples

**Version:** 3.0.3
**Category:** World Generation

## Description

Replaces vanilla desert temples with much larger, more detailed structures. Features multiple floors, hidden rooms, traps, and valuable loot that make desert exploration far more rewarding.

## Key Features

- Massive desert temple structures with multiple floors
- Hidden rooms and secret passages
- Improved trap mechanics
- Better loot tables
- Architecturally detailed with sand-themed decorations

## Configuration

Config file: `config/yungsbetterdeserttemples.toml`

Key settings:
- Structure spawn rate and spacing
- Loot multiplier
- Trap difficulty

## Tips

- Search for hidden rooms behind walls and under floors
- The traps are more dangerous than vanilla - approach carefully
- Bring a pickaxe for mining through walls
- Great source of early-mid game loot
