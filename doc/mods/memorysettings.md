# Memory Settings

**Version:** 1.x
**Category:** Performance

## Description
Memory Settings provides advanced memory management options for Minecraft, allowing fine-tuning of memory allocation and garbage collection for optimal performance.

## Key Features
- Advanced memory management
- Garbage collection optimization
- Memory allocation tuning
- Performance monitoring tools
- Detailed memory statistics

## Configuration
Config file: `config/memorysettings.toml`

Key settings:
- `enabled`: Enable memory settings (recommended: true)
- `memoryAllocation`: Memory allocation strategy
- `gcOptimization`: Garbage collection optimization level
- `monitorMemory`: Enable memory monitoring

## Tips
- Works well with ModernFix and FerriteCore for comprehensive memory optimization
- Monitor memory usage to find optimal settings
- Particularly important for modpacks with many mods
- Adjust based on your available system RAM
