# Not Enough Crashes

**Version:** 4.4.7+1.20.1-forge
**Category:** Utility & Library

## Description
Not Enough Crashes allows the game to recover from certain crashes instead of closing completely. It provides crash recovery and better crash reporting.

## Key Features
- Crash recovery
- Continue after crash
- Enhanced crash reports
- Mod tracking
- Crash history

## Configuration
- Config: `config/notenoughcrashes.toml`

## Tips
- Enable to prevent full game closure on crashes
- Some crashes are unrecoverable
- Useful during mod testing and development
- Check logs after recovery for root cause
