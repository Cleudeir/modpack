# Repurposed Structures

**Version:** 7.1.15
**Category:** World Generation

## Description

Repurposed Structures takes vanilla Minecraft structures and adds them to new biomes with biome-appropriate variants. This greatly expands exploration by making structures like mineshafts, pillager outposts, and bastions appear in new contexts.

## Key Features

- Vanilla structures in new biomes (e.g., jungle temples in swamps, nether fortresses in overworld)
- Biome-themed variants of existing structures
- New loot tables for each variant
- Compatible with many other worldgen mods
- Configurable per-structure

## Configuration

Config file: `config/repurposed_structures.toml`

Key settings:
- Enable/disable individual structure variants
- Spawn rate and spacing for each structure
- Biome blacklist/whitelist

## Tips

- Check config to disable structures that conflict with other mods
- Some variants are rarer than others
- Great for exploration-focused modpacks
- Works well alongside YUNG's mods
