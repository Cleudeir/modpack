# Villagers Respawn

**Version:** 1.20.1-1.1.0
**Category:** Mobs & Entities

## Description
Villagers Respawn makes villagers respawn after death, ensuring villages remain populated. This prevents villages from becoming empty after raids or other events.

## Key Features
- Villagers respawn after death
- Configurable respawn timers
- Maintains village population
- Works with modded villager types
- Simple configuration

## Configuration
Config file: `config/villagersrespawn.toml`

Key settings:
- Respawn timer length
- Population cap per village
- Enable/disable toggle
- Compatibility settings

## Tips
- Helps maintain trading options long-term
- Combine with Guard Villagers for safer villages
- Adjust respawn times based on difficulty
- Works with custom village structures
