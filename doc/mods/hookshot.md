# Hookshot

**Version:** 1.0
**Category:** Exploration & Navigation

## Description
Hookshot adds a Zelda-style hookshot item to Minecraft. It allows players to grapple to blocks and pull themselves toward them, similar to the classic Legend of Zelda mechanic.

## Key Features
- Throw hookshot to latch onto blocks
- Pull player toward hook location
- Can be used for vertical and horizontal movement
- Works with most solid blocks
- Simple right-click activation
- Durable tool with limited uses

## Configuration
No config file found - uses default settings.

## Tips
- Right-click to throw hookshot at a block
- Must be within range to latch on
- Consumes durability with each use
- Great for exploring caves and climbing cliffs
- Can be combined with other movement mods
- Simple and easy to use
