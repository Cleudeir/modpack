# Mobs Properties Randomness

**Version:** 1.20.1-1.0.0
**Category:** Mobs & Entities

## Description
Mobs Properties Randomness adds random attribute variations to spawned mobs, making each encounter unique. Mobs can have different health, damage, speed, and other attributes.

## Key Features
- Random health variations per mob
- Damage multipliers
- Speed variations
- Size variations
- Visual indicators for modified mobs
- Configurable ranges for all attributes

## Configuration
Config file: `config/mobspropertiesrandomness.toml`

Key settings:
- Attribute range settings
- Spawn chance for modified mobs
- Visual effect toggles
- Attribute type toggles

## Tips
- Watch for larger or faster mobs—they're more dangerous
- Higher-tier mobs have wider attribute ranges
- Some attributes are indicated by particle effects
- Difficulty settings affect attribute ranges
