# Supplementaries

**Version:** 2.8.17
**Category:** Building & Decoration

## Description
Supplementaries is a Vanilla+ mod that adds a large variety of decorative and functional blocks to enhance building and decoration. It focuses on items that feel like they belong in vanilla Minecraft but add much-needed variety for builders.

## Key Features
- Lanterns, cages, and lighting variants
- Flags and banners with customization
- Bookshelves and display cases
- Signs, banners, and wall decorations
- Torches and redstone torch variants
- Item frames and entity display blocks
- Planters and flower pots
- Quivers, bottles, and functional decorative items

## Configuration
Config file: `config/supplementaries-common.toml`
- Toggle individual blocks
- Customize interaction behaviors

## Tips
- The lantern and torch variants are especially popular for medieval/fantasy builds
- Pairs well with Ecologics and Handcrafted for comprehensive decoration options
