# Trash Slot

**Version:** 1.12.x
**Category:** Quality of Life

## Description
Trash Slot adds a small trash can slot to your inventory screen, allowing you to quickly delete unwanted items without dropping them on the ground.

## Key Features
- Dedicated trash slot in inventory
- One-click item deletion
- Confirmation for rare/valuable items
- Configurable protected items
- Works in survival mode only
- Clean UI integration

## Configuration
Config file: `config/trashslot.toml`

Key settings:
- `trashSlotPosition` - Position of the trash slot
- `protectedItems` - Items that require confirmation
- `enableConfirmation` - Require confirmation for deletion
- `blacklist` - Items that cannot be trashed

## Tips
- Click items into the trash slot to delete them
- Shift-click for quick deletion
- Configure protection for valuable items like diamonds
- Great for cleaning up junk while mining
- Items deleted this way cannot be recovered
