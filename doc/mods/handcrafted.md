# Handcrafted

**Version:** 3.0.6
**Category:** Building & Decoration

## Description
Handcrafted is a furniture and decoration mod that adds a wide variety of realistic, detailed furniture and decorative blocks to Minecraft. It focuses on creating cozy, detailed interiors with items like chairs, tables, shelves, lamps, and more.

## Key Features
- Chairs, stools, and seating options
- Tables (dining, coffee, side tables)
- Shelves, cabinets, and storage furniture
- Lamps and lighting fixtures
- Decorative items like paintings, curtains, and cushions
- Wall-mounted items (shelves, hooks, coat racks)
- Benches, sofas, and couches
- Bookshelves and book stacks

## Configuration
Config file: `config/handcrafted.toml`
- Enable/disable specific blocks
- Adjust placement behavior for some items

## Tips
- Combine with Every Compat for additional wood type variants
- Works well with Supplementaries for a complete vanilla+ decoration setup
- Some items have multiple rotation states when placed
