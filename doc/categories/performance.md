## Recommended Settings

For best performance with these mods:
1. Enable Embeddium's Sodium rendering
2. Set ModernFix to aggressive mode
3. Enable FerriteCore's memory optimization
4. Use Entity Culling to reduce render overhead

## Tips

- Monitor RAM usage with F3 debug screen
- Use Spark to profile performance issues
- Adjust render distance based on your system
- Enable async chunk loading for smoother exploration
