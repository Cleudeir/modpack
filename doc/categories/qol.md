## Essential QoL Features

- **JEI**: Press R for recipes, U for uses
- **Jade**: Look at blocks for information
- **Inventory Sorting**: Middle-click to sort
- **Trash Slot**: Shift+click to delete items

## Keybindings

Default keybindings (check Controlling to customize):
- **R**: Show recipes (JEI)
- **U**: Show uses (JEI)
- **J**: Toggle Jade overlay
- **F**: Zoom (Just Zoom)

## Performance Notes

- Most QoL mods have minimal performance impact
- Sound mods may increase CPU usage slightly
- Animation mods are generally lightweight
