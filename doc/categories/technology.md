## Create Mod Guide

Create is the primary automation mod. Key concepts:
- **Rotation**: Generated by water wheels, windmills, etc.
- **Stress**: Power consumption of machines
- **Kinetics**: Gears, shafts, and mechanical components
- **Processing**: Millstones, saws, mixers, etc.

## Automation Tips

- Start with Wooden Hopper for early transport
- Use Create for complex automation
- Iron Chests for expanded storage
- Falling Tree for efficient wood gathering

## Configuration

Key config files:
- `config/create-common.toml` - Create settings
- `config/createaddition-common.toml` - Create additions
- `config/woodenhopper-server.toml` - Wooden Hopper
