## World Generation Tips

- Use Nature's Compass to find specific biomes
- Use WITs to locate structures
- Enable better structures in config for more exploration
- Consider using Biome Spawn Point for themed starts

## Configuration

Most worldgen mods can be configured in `config/` directory:
- Structure generation rates
- Biome weights and frequencies
- Spawn point customization
