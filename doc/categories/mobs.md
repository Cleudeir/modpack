## Mob Configuration Tips

- Use In Control to fine-tune spawning rules
- Adjust mob difficulty with Scaling Health
- Configure zombie awareness for smarter enemies
- Use Bad Mobs to remove performance-heavy mobs

## Performance Considerations

- Too many custom mobs can impact performance
- Use Entity Culling to optimize rendering
- Consider mob caps in spawning configs
