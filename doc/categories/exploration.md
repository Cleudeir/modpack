## Navigation Tips

- Use Waystones for fast travel network
- Advanced Compass shows distance to structures
- WITs helps locate specific structures
- World Genre Visited tracks exploration progress

## Movement Abilities

- **ParCool**: Wall climbing, rolling, sliding
- **Grappling Hook**: Zip to surfaces
- **Hookshot**: Pull yourself to blocks

## Exploration Strategy

1. Set up Waystones at key locations
2. Use Advanced Compass to navigate
3. Track progress with World Genre Visited
4. Use ParCool for efficient movement

## World Stripper Usage

- Strip layers to find ores
- Clear areas for building
- Create flat areas for construction
