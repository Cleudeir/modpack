## Essential Libraries

- **Forge**: Core mod loader
- **Architectury**: Cross-platform compatibility
- **Balm**: Config management abstraction
- **KubeJS**: JavaScript scripting engine

## Development Tools

- **Spark**: Profile server performance
- **Crash Utilities**: Better crash reports
- **Not Enough Crashes**: Recover from crashes
- **Log Begone**: Filter noisy logs

## Configuration

- Config files in config/ directory
- Use Configured for in-game config screens
- KubeJS scripts in kubejs/ directory
- CraftTweaker scripts in scripts/ directory

## Tips

- Do not remove library mods (other mods depend on them)
- Use Spark to diagnose performance issues
- Check crash reports for mod conflicts
- Use KubeJS for custom content
